## 斐波那契数列

题号： BM62
描述： 1,1,2,3,5
思路： 


### 迭代（标准解法）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```go
func Fibonacci(n int) int {
    if n <= 2 {
        return 1
    }
    a, b := 0, 1
    for i := 0; i < n; i++ {
        a, b = b, a+b
    }
    return a
}
```

或

```go
func Fibonacci(n int) int {
    if n <= 2 {
      	return 1
    }
    a, b := 1, 1 // 前两次状态
    var c int
    for i := 3; i <= n; i++ {
        c = a + b
        a = b
        b = c
    }
    return c
}
```



### 递归解法

存在大量重复计算

```go
func Fibonacci( n int ) int {
    if n<=2{
        return 1
    }
    return Fibonacci(n-1)+Fibonacci(n-2)
}
```



### 记忆化递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$ + 递归栈

```python
def Fibonacci(self, n: int, memo: dict) -> int:
    if n <= 1:
        return n

    if n not in memo:
        memo[n] = fib(n - 1, memo) + fib(n - 2, memo)

    return memo[n]
```



### 其它

矩阵快速幂 和 Fast Doubling（快速倍增法）

时间复杂度： $O(\log n)$

```python
def fib(n):
    if n == 0:
        return 0, 1

    a, b = fib(n // 2)

    c = a * (2 * b - a)
    d = a * a + b * b

    if n % 2 == 0:
        return c, d
    else:
        return d, c + d

def Fibonacci(n):
    return fib(n)[0]
```
