## 零钱兑换

题号： BM70， LC322
描述： 给定数组arr，arr中所有的值都为正整数且不重复。每个值代表一种面值的货币，每种面值的货币可以使用任意张，再给定一个aim，代表要找的钱数，求组成aim的最少货币数。如果无解，请返回-1.

**状态定义**： `dp[i]`表示凑出金额 `i` 所需要的最少硬币数量。

**状态转移**
假设最后选择一枚面值为 `coin` 的硬币。
那么之前需要凑：`i - coin`金额。
如果：`dp[i-coin]`有解，那么：
$$
dp[i]=min(dp[i],dp[i−coin]+1)
$$
**初始化**： 除了`dp[0]=0`, 其它金额一开始认为不可达。`dp[i]=aim+1`作为无穷大，因硬币数量不会超过aim。

时间复杂度： $O(n*aim)$
空间复杂度： $O(aim)$

```python
class Solution:
    def coinChange(self, arr, aim):
        # 初始化为无穷大
        dp = [aim + 1] * (aim + 1)
        # 金额0需要0枚硬币
        dp[0] = 0

        # 遍历目标金额
        for i in range(1, aim + 1):
            # 遍历所有面值的硬币
            for coin in arr:
                # 目标金额大于等于硬币面值
                if i >= coin:
                    dp[i] = min(
                        dp[i],
                        dp[i-coin] + 1
                    )

        return -1 if dp[aim] == aim + 1 else dp[aim]
```
