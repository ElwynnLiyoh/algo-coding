## 打家劫舍

题号： BM78，LC198
描述： 
你是一个经验丰富的小偷，准备偷沿街的一排房间，每个房间都存有一定的现金，为了防止被发现，你不能偷相邻的两家，即，如果偷了第一家，就不能再偷第二家；如果偷了第二家，那么就不能偷第一家和第三家。
给定一个整数数组nums，数组中的元素表示每个房间存有的现金数额，请你计算在不被发现的前提下最多的偷窃金额。

### DP

**状态定义**：`dp[i]`表示考虑前 `i` 家房子时，最多能偷多少钱。
**状态转移**：
$$
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])
$$
**初始条件**：注意这里的 `i` 是“房子的数量”，所以：
```python
dp[0] = 0 # 一家都不偷 
dp[1] = nums[0]
```
`nums[i-1]`指的是第`i`家的金额

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def rob(self, nums):
        n = len(nums)

        if n == 0:
            return 0

        dp = [0] * (n + 1)
        dp[1] = nums[0]

        for i in range(2, n + 1):
            # 不偷第 i 家：dp[i - 1]
            # 偷第 i 家：第 i-1 家不能偷，所以是 dp[i - 2] + nums[i - 1]
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i - 1])

        return dp[n]
```

**压缩（迭代）**

因为只依赖`dp[i-1]和dp[i-2]`
时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        prev2 = 0  # dp[i - 2]
        prev1 = 0  # dp[i - 1]

        for money in nums:
            # cur = max(prev1, prev2 + money)
            # prev2 = prev1
            # prev1 = cur
            prev2, prev1 = prev1, max(prev1, prev2 + money)

        return prev1
```


### 递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
from functools import cache
class Solution:
    # 写法一
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        memo = {}

        def dfs(i):
            if i >= n:
                return 0
            if i in nums:
	            return memo[i]
            skip = dfs(i + 1)
            take = nums[i] + dfs(i + 2)
            memo[i] = max(skip, take)
            return memo[i]

        return dfs(0)
    
    # 写法二
    def rob2(self, nums: List[int]) -> int:
        n = len(nums)

        @cache
        def dfs(i):
            # 已经没有房子可以偷了
            if i >= n:
                return 0

            # 不偷当前房子
            skip = dfs(i + 1)
            # 偷当前房子，因此下一家不能偷
            take = nums[i] + dfs(i + 2)
            return max(skip, take)

        return dfs(0)
```

### 变种：打印出路径

```python
class Solution:
    def rob(self, nums: list[int]) -> tuple[int, list[int]]:
        n = len(nums)
        if n == 0:
            return 0, []

        dp = [0] * (n + 1)
        dp[1] = nums[0]

        # dp[i] 表示偷前 i 家能够获得的最大金额
        for i in range(2, n + 1):
            dp[i] = max(
                dp[i - 1],              # 不偷第 i 家
                dp[i - 2] + nums[i - 1] # 偷第 i 家
            )

        # 从最后一个状态反向恢复偷窃路径
        path = []
        i = n

        while i >= 1:
            # 不偷第 i 家
            if dp[i] == dp[i - 1]:
                i -= 1
            else:
                # 偷第 i 家，（记录其数组下标的话是i-1）
                path.append(i)
                i -= 2

        # 反向恢复得到的路径，需要翻转
        path.reverse()
        return dp[n], path
```
