## 最小花费爬楼梯

题号： BM64
描述： 
给定一个整数数组 cost cost  ，其中 cost[i] cost[i]  是从楼梯第i i 个台阶向上爬需要支付的费用，下标从0开始。一旦你支付此费用，即可选择向上爬一个或者两个台阶。  
你可以选择从下标为 0 或下标为 1 的台阶开始爬楼梯。  
请你计算并返回达到楼梯顶部的最低花费。

思路： 

dp[i] = 到达位置 i 的最小花费
$dp[i]=min(dp[i−1]+cost[i−1], dp[i−2]+cost[i−2])$
$dp[0]=dp[1]=0$，因为可以从0或1开始，都不需要花费。

### 完整写法

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def minCostClimbingStairs(self, cost: List[int]) -> int:
    n = len(cost)
    dp = [0] * (n + 1)
    dp[0], dp[1] = 0, 0
    for i in range(2, n + 1):
        dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
    return dp[n]
```



### 优化空间

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
# 写法一
def minCostClimbingStairs(self, cost: List[int]) -> int:
    pre1, pre2 = 0, 0 # pre1前一个， pre2前二个
    for i in range(2, len(cost) + 1):
        cur = min(pre1 + cost[i - 1], pre2 + cost[i - 2])
        pre2 = pre1
        pre1 = cur
    # cur代表当前花费，而cur已赋值给了pre1
    return pre1
 
# 写法二
def minCostClimbingStairs(self, cost: List[int]) -> int:
    n = len(cost)
    a, b = 0, 0	 # 这里a是前二个，b是前一个
    for i in range(2, n + 1):
        a, b = b, min(b + cost[i - 1], a + cost[i - 2])
	# 最后计算的结果已赋值给b
    return b
```
