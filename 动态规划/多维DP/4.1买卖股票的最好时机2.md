## 买卖股票的最好时机2

题号： BM81,  LC122
描述： 可以多次买卖该只股票，但是再次购买前必须卖出之前的股票。

**状态定义**： 

```python
dp[i][0]：第 i 天结束时，不持有股票的最大现金
dp[i][1]：第 i 天结束时，持有股票的最大现金
```

**状态转移**：只有一种情况不同

|            | 股票 I                    | 股票 II                   |
| ---------- | ----------------------- | :---------------------- |
| 交易次数       | 最多 1 次                  | 无限次                     |
| `dp[i][0]` | `max(昨天不持股, 昨天持股+今天价格)` | 相同                      |
| `dp[i][1]` | `max(昨天持股, -今天价格)`      | `max(昨天持股, 昨天不持股-今天价格)` |

**初始条件**：不持股显然为 0，持股就需要减去第 1 天（下标为 0）的股价
```python
dp[0][0] =0;
dp[0][1] = -prices[0];
```

时间复杂度： $O(n)$
空间复杂度： $O(n​)$

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        n = len(prices)
        if n <= 1:
            return 0

        # dp[i][0]：第 i 天结束时不持股的最大现金
        # dp[i][1]：第 i 天结束时持股的最大现金
        dp = [[0] * 2 for _ in range(n)]

        # 第 0 天
        dp[0][0] = 0
        dp[0][1] = -prices[0]

        for i in range(1, n):
            # 今天不持股：
            # 1. 昨天就不持股
            # 2. 昨天持股，今天卖出
            dp[i][0] = max(
                dp[i - 1][0],
                dp[i - 1][1] + prices[i]
            )

            # 今天持股：
            # 1. 昨天就持股
            # 2. 今天买入
            dp[i][1] = max(
                dp[i - 1][1],
                dp[i - 1][0] - prices[i] # 只有这里不同
            )

        return dp[n - 1][0]
```



压缩

只依赖前一天。

```plaintext
cash  # 当前不持股状态
hold  # 当前持股状态
```

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        cash = 0
        hold = -prices[0]

        for price in prices[1:]:
            cash = max(cash, hold + price)
            hold = max(hold, cash - price)

        return cash
```


### 贪心

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        if n <= 1:
            return 0

        profit = 0
        for i in range(1, n):
            if prices[i] > prices[i - 1]:
                profit += prices[i] - prices[i - 1]

        return profit
```
