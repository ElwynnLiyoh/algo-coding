## 矩阵的最小路径和

题号： BM68
描述： 给定一个 n * m 的矩阵 a，从左上角开始每次只能向右或者向下走，最后到达右下角的位置，路径上所有的数字累加起来就是路径和，输出所有的路径中最小的路径和。

### 多维DP

**定义状态**： `dp[i][j]`表示从左上角到`(i,j)`位置时，能够得到的最小路径和。
注意：这里是**到达当前格子**，所以是正向 DP。
**状态转移**
$$
dp[i][j]=min(dp[i−1][j],dp[i][j−1])+a[i][j]
$$
**初始化**： 左上角，第一行（只能从左边过来），第一列（只能从上面过来）

时间复杂度： $O(nm)$
空间复杂度： $O(nm)$

```python
class Solution:
    def minPathSum(self, matrix):
        n = len(matrix)
        m = len(matrix[0])

        dp = [[0] * m for _ in range(n)]
        dp[0][0] = matrix[0][0]

        # 第一行
        for j in range(1, m):
            dp[0][j] = dp[0][j-1] + matrix[0][j]

        # 第一列
        for i in range(1, n):
            dp[i][0] = dp[i-1][0] + matrix[i][0]

        # 其它位置
        for i in range(1, n):
            for j in range(1, m):
                dp[i][j] = matrix[i][j] + min(dp[i - 1][j], dp[i][j - 1])

        return dp[n-1][m-1]
```



### 一维DP



```python
class Solution:
    def minPathSum(self, matrix):

        n = len(matrix)
        m = len(matrix[0])

        dp = [0] * m

        dp[0] = matrix[0][0]

        # 第一行
        for j in range(1, m):
            dp[j] = dp[j-1] + matrix[0][j]

        for i in range(1, n):

            # 第一列
            dp[0] += matrix[i][0]

            for j in range(1, m):
                dp[j] = min(
                    dp[j],       # 上方
                    dp[j-1]      # 左方
                ) + matrix[i][j]

        return dp[m-1]
```
