## 最长公共子序列

**Longest Common Subsequence，LCS）**

题号： BM65
描述：给定两个字符串str1和str2，输出两个字符串的最长公共子序列。如果最长公共子序列为空，则返回"-1"。
输入： "1A2C3D4B56", "B1D23A456A"
输出： “123456”
即不要求连续，只要相对位置正确就行。
思路： 
状态转移方程：
$$
dp[i][j]= \begin{cases} dp[i-1][j-1]+1 & str1[i-1]=str2[j-1]\\ \max(dp[i-1][j],dp[i][j-1]) & str1[i-1]\ne str2[j-1] \end{cases}​​
$$

>  `dp[i][j]` 表示str1 的**前** i 个字符和 str2 的**前** j 个字符的最长公共子序列长度。

时间复杂度： $O(nm)$
空间复杂度： $O(nm)$

### 只求长度

题号： DP19，LC1143

```python
def lcs_length(str1, str2):
    n = len(str1)
    m = len(str2)

    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if str1[i - 1] == str2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[n][m]
```

优化

空间O(m)

```python
def lcs_length(str1, str2):
    n = len(str1)
    m = len(str2)

    dp = [0] * (m + 1)

    for i in range(1, n + 1):
        prev = 0  # 相当于更新前的 dp[i-1][j-1]

        for j in range(1, m + 1):
            temp = dp[j]  # 保存更新前的 dp[i-1][j]

            if str1[i - 1] == str2[j - 1]:
                dp[j] = prev + 1
            else:
                dp[j] = max(dp[j], dp[j - 1])

            prev = temp

    return dp[m]
```



递归

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        n = len(text1)
        m = len(text2)

        @cache
        def dfs(n, m):
            if n < 0 or m < 0:
                return 0
            if text1[n] == text2[m]:
                return dfs(n - 1, m - 1) + 1
            else:
                return max(dfs(n - 1, m), dfs(n, m - 1))

        return dfs(n - 1, m - 1)
```



### 求字符串


```python
class Solution:
    def LCS(self, s1: str, s2: str) -> str:
        n = len(s1)
        m = len(s2)

        if n == 0 or m == 0:
            return "-1"

        # dp[i][j]：
        # s1 前 i 个字符和 s2 前 j 个字符
        # 的最长公共子序列长度
        dp = [[0] * (m + 1) for _ in range(n + 1)]

        # 计算 DP
        for i in range(1, n + 1):
            for j in range(1, m + 1):

                if s1[i - 1] == s2[j - 1]:
                    # 当前两个字符相同，可以加入 LCS
                    dp[i][j] = dp[i - 1][j - 1] + 1

                else:
                    # 当前两个字符不同：
                    # 要么舍弃 s1[i-1]
                    # 要么舍弃 s2[j-1]
                    dp[i][j] = max(
                        dp[i - 1][j],
                        dp[i][j - 1]
                    )

        # 没有公共子序列
        if dp[n][m] == 0:
            return "-1"

        # 从右下角开始恢复 LCS
        result = []

        i = n
        j = m

        while i > 0 and j > 0:

            if s1[i - 1] == s2[j - 1]:
                # 当前字符属于 LCS
                result.append(s1[i - 1])
                i -= 1
                j -= 1

            elif dp[i - 1][j] >= dp[i][j - 1]:
                # 上面的状态更优，向上走
                i -= 1

            else:
                # 左边的状态更优，向左走
                j -= 1

        # 因为恢复过程是从后往前，
        # 所以需要反转
        result.reverse()

        return "".join(result)
```

优化

```python
class Solution:
    def LCS(self, s1: str, s2: str) -> str:
        if not s1 or not s2:
            return "-1"

        m = len(s2)

        # dp[j]：
        # 当前处理到 s1[i] 时，
        # 以 s2[j] 结尾的最长公共子序列
        dp = [""] * m

        for c in s1:

            # prev 表示：
            # 更新 dp[j] 之前的 dp[j-1]
            # 也就是二维 DP 中的 dp[i-1][j-1]
            prev = ""

            for j in range(m):

                # 保存修改前的 dp[j]
                # 因为后面还需要用它更新 prev
                old = dp[j]

                if c == s2[j]:
                    # 当前两个字符相同，
                    # 可以把 c 接到前面的公共子序列后面
                    if len(dp[j]) < len(prev) + 1:
                        dp[j] = prev + c

                else:
                    # 当前字符不相同，
                    # 需要把更长的结果继续向右传递
                    if len(dp[j]) < len(prev):
                        dp[j] = prev

                # old 是更新前的 dp[j]
                # 它将成为下一列的 prev 候选
                if len(old) > len(prev):
                    prev = old

        # dp 中保存的是不同结尾位置对应的候选答案
        # 找最长的那个
        answer = ""

        for sequence in dp:
            if len(sequence) > len(answer):
                answer = sequence

        return answer if answer else "-1"
```



### 套路总结

你可以把这道题总结成：

### ① 定义状态

```
dp[i][j]=str1 前 i 个字符和str2 前 j 个字符的 LCS 长度
```

### ② 找最后一个字符

比较：

```
str1[i-1]str2[j-1]
```

### ③ 相等

```
dp[i][j] = dp[i-1][j-1] + 1
```

### ④ 不相等

```
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

### ⑤ 求完 DP 后反向恢复答案

```
右下角  ↓逐步向左/向上/左上移动  ↓遇到相同字符就加入答案  ↓最后 reverse
```
