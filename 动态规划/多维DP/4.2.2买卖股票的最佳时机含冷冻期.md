## 买卖股票的最佳时机含冷冻期

题号： LC309
描述： 与2的最大区别在于 卖出股票后，**第二天不能买入**，必须等待一天。
**状态定义**： 
```plaintext
dp[i][0]：第 i 天结束，持有股票的最大现金
dp[i][1]：第 i 天结束，不持股且处于冷冻期的最大现金
          （今天刚卖出）
dp[i][2]：第 i 天结束，不持股且非冷冻期的最大现金
          （之前卖出，冷冻期已经结束）
```
状态关系：
```plaintext
        买入
非冷冻期 -----> 持股
   ↑             |
   |             |
   |             ↓
冷冻期 <------- 卖出
```

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        if n <= 1:
            return 0

        neg_inf = float("-inf")

        # 0: 持股
        # 1: 冷冻期（今天卖出）
        # 2: 非冷冻期不持股
        dp = [[0] * 3 for _ in range(n)]

        dp[0][0] = -prices[0]
        dp[0][1] = neg_inf
        dp[0][2] = 0

        for i in range(1, n):
            price = prices[i]

            # 持股
            dp[i][0] = max(dp[i-1][0],dp[i-1][2] - price)
            # 今天卖出
            dp[i][1] = dp[i-1][0] + price
            # 不持股非冷冻期
            dp[i][2] = max(dp[i-1][2],dp[i-1][1])

        # 最后一天不能处于持股状态
        return max(dp[-1][1], dp[-1][2])
```

空间压缩

每一天只依赖前一天，因此只保留三个变量：

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        if len(prices) <= 1:
            return 0

        neg_inf = float("-inf")

        hold = -prices[0]  # 持股
        freeze = neg_inf   # 冷冻期
        cash = 0           # 非冷冻期不持股

        for price in prices[1:]:
            prev_hold = hold
            prev_freeze = freeze
            prev_cash = cash # 由于没有依赖关系，所以旧cash也可以不需要

            # 今天持股
            hold = max(prev_hold, prev_cash - price)

            # 今天卖出，进入冷冻期
            # 今天卖出，只能卖昨天持有的股票。
            freeze = prev_hold + price

            # 冷冻期结束或者继续保持现金
            # 如果freeze错了，这里也一定错。
            cash = max(prev_cash, prev_freeze)

        return max(cash, freeze)
```
