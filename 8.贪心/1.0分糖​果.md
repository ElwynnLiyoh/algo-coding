## 分糖​果

题号： BM95
描述： 
1. 每个孩子不管得分多少，起码分到一个糖果。
2. 任意两个相邻的孩子之间，得分较多的孩子必须拿多一些糖果。(若相同则无此限制)

思路： 同时满足左贪心和右贪心，故需要左右各扫描一次。都是以积分判断，都是给糖果赋值。
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def candy(self, arr: List[int]) -> int:
    n = len(arr)
    candies = [1] * n

    # 从左向右
    for i in range(1, n):
        if arr[i] > arr[i - 1]:
            candies[i] = candies[i - 1] + 1

    # 从右向左
    for i in range(n - 2, -1, -1):
        if arr[i] > arr[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)

    return sum(candies)
```

例如：输入 [2, 1, 4, 3, 1]
第一轮（左到右）： [1, 1, 2, 1, 1]
第二轮（右到左）： [2, 1, 2, 2, 1]

go版本
```go
func candy(arr []int) int {
	n := len(arr)
	candies := make([]int, n)
	candies[0] = 1
	for i := 1; i < n; i++ {
		if arr[i] > arr[i-1] {
			candies[i] = candies[i-1] + 1
		} else {
			candies[i] = 1
		}
	}

	for i := n - 2; i >= 0; i-- {
		if arr[i] > arr[i+1] && candies[i] < candies[i+1]+1 {
			candies[i] = candies[i+1] + 1
		}
	}

	sum := 0
	for _, num := range candies {
		sum += num
	}
	return sum
}
```

优化：可以放到第二轮循环里顺便求和，就可以少一次循环
```go
	sum := candies[n-1]

		}
```
