## 括号生成

题号： BM60, LC22
描述： 给出n对括号，请编写一个函数来生成所有的由n对括号组成的合法组合。  
例如，给出n=3，解集为：
"((()))", "(()())", "(())()", "()()()", "()(())"

**思路**： 
两个核心规则
规则一：左括号不能超过 n，因为总共只有 `n` 对括号。
规则二：右括号不能超过左括号。这是因为从左到右看，右括号已经多于左括号，后面再怎么添加也不可能变成合法括号序列。
维护：

```python
left   # 已经使用了多少个 '('
right  # 已经使用了多少个 ')'
```

时间复杂度： $O(nC_n)$，`n` 对括号的合法组合数量是第 `n` 个 **Catalan 数**。
空间复杂度： $O()$，共有 $C_n$ 个合法括号组合，其中 $C_n$是 Catalan 数。每个结果长度为 $2n$，因此生成所有结果的时间复杂度为 **O(nCₙ)**，其中 $C_n=\frac{1}{n+1}\binom{2n}{n}$。如果不计算返回结果，回溯的辅助空间复杂度为 **O(n)**；如果计算结果存储，则为 **O(nCₙ)**。

```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        ans = []
        path = []

        def dfs(left, right):
            if left == n and right == n:
                ans.append("".join(path))
                return

            # 放左括号
            if left < n:
                path.append("(")
                dfs(left + 1, right)
                path.pop()

            # 放右括号
            if right < left:
                path.append(")")
                dfs(left, right + 1)
                path.pop()

        dfs(0, 0)
        return ans
```

**回溯 = DFS + 状态 + 剪枝。**
其中 `left`、`right` 就是这个 DFS 的状态。
