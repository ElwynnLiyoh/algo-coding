## 岛屿数量

题号： BM57，LC200
描述： 给一个01矩阵，1代表是陆地，0代表海洋， 如果两个1相邻，那么这两个1属于同一个岛。我们只考虑上下左右为相邻。

其实是在求**图的连通分量**有多少。

### DFS

浓缩思路：

```python
for 每一个格子:
    if 是陆地:
        岛屿数量 += 1
        DFS，把整个岛淹掉
```

时间复杂度： $O(mn)$，其中mm、nn为矩阵的长和宽，需要遍历整个矩阵，每次dfs搜索需要经过每个值为1的元素，但是最坏情况下也只是将整个矩阵变成0，因此相当于最坏遍历矩阵2次
空间复杂度： $O(mn)$，最坏情况下整个矩阵都是1，递归栈深度为mnmn

```python
class Solution:
    def solve(self, grid):
        if not grid or not grid[0]:
            return 0

        m = len(grid)
        n = len(grid[0])
        ans = 0

        def dfs(i, j):
            # 越界
            if i < 0 or i >= m or j < 0 or j >= n:
                return

            # 海洋，或者已经访问过
            if grid[i][j] != '1':
                return

            # 标记为已经访问
            grid[i][j] = '0'

            # 上
            dfs(i - 1, j)
            # 下
            dfs(i + 1, j)
            # 左
            dfs(i, j - 1)
            # 右
            dfs(i, j + 1)

        for i in range(m):
            for j in range(n):
                if grid[i][j] == '1':
                    ans += 1
                    dfs(i, j)

        return ans
```



### BFS

广度优先需要用到队列。

- 时间复杂度：$O(nm)$，其中m*m*、n*n*为矩阵的长和宽，需要遍历整个矩阵，每次bfs搜索需要经过每个值为1的元素，但是最坏情况下也只是将整个矩阵变成0，因此相当于最坏遍历矩阵2次
- 空间复杂度：$(min(n,m))$，bfs最坏情况队列大小为长和宽的较小值

```python
from collections import deque
class Solution:
    def solve(self, grid):
        if not grid or not grid[0]:
            return 0

        m = len(grid)
        n = len(grid[0])
        ans = 0

        directions = [
            (-1, 0),  # 上
            (1, 0),   # 下
            (0, -1),  # 左
            (0, 1)    # 右
        ]

        for i in range(m):
            for j in range(n):
                if grid[i][j] != '1':
                    continue

                # 发现一个新的岛屿
                ans += 1

                # BFS
                queue = deque([(i, j)])
                grid[i][j] = '0'

                while queue:
                    x, y = queue.popleft()

                    for dx, dy in directions:
                        nx = x + dx
                        ny = y + dy

                        # 越界
                        if nx < 0 or nx >= m or ny < 0 or ny >= n:
                            continue

                        # 不是未访问的陆地
                        if grid[nx][ny] != '1':
                            continue

                        # 标记为已访问
                        grid[nx][ny] = '0'

                        # 加入队列
                        queue.append((nx, ny))

        return ans
```

> [!TIPS]
> deque性能比queue好不少，因为`queue.Queue` 是为**多线程安全队列**设计的，它的 `put()`、`get()`、`empty()` 等操作涉及线程同步机制。
