## 矩阵最长递增路径

题号： BM61
描述： 给定一个 n 行 m 列矩阵 matrix ，矩阵内所有数均为非负整数。 你需要在矩阵中找到一条最长路径，使这条路径上的元素是递增的。并输出这条最长路径的长度。可以往上下左右方向移动，不能重复。
###  DFS

`memo` 最终会记录每个位置的结果，代表从这个位置出发，最长还能走多少个节点。

时间复杂度： $O(nm)$，因为有memo，每个格子的dfs最多真正计算一次。
空间复杂度： $O(nm)$，memo和递归栈

```python
class Solution:
    def solve(self, matrix):
        n = len(matrix)
        m = len(matrix[0])

        memo = [[0] * m for _ in range(n)]
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

        def dfs(i, j):
            # 已经计算过
            if memo[i][j] != 0:
                return memo[i][j]

            # 至少包含自己
            ans = 1
            for di, dj in directions:
                ni = i + di
                nj = j + dj

                # 越界
                if ni < 0 or ni >= n or nj < 0 or nj >= m:
                    continue

                # 必须严格递增
                if matrix[ni][nj] <= matrix[i][j]:
                    continue

                ans = max(ans, 1 + dfs(ni, nj))

            memo[i][j] = ans
            return ans

        ans = 0

        for i in range(n):
            for j in range(m):
                ans = max(ans, dfs(i, j))

        return ans
```

```python
def dfs(i, j):
    if memo[i][j]:
        return memo[i][j]

    ans = 1

    for 每个方向:
        if 可以走:
            ans = max(ans, 1 + dfs(下一格))

    memo[i][j] = ans
    return ans
```



### BFS

拓扑排序求解DAG（有向无环图）最长路径

时间复杂度： $O(nm)$，因为有indegree
空间复杂度： $O(nm)$，

```python
from collections import deque
class Solution:
    def solve(self, matrix):
        n = len(matrix)
        m = len(matrix[0])

        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

        # 入度
        indegree = [[0] * m for _ in range(n)]

        # 建图：小 -> 大
        for i in range(n):
            for j in range(m):
                for di, dj in directions:
                    ni = i + di
                    nj = j + dj

                    if 0 <= ni < n and 0 <= nj < m:
                        if matrix[ni][nj] > matrix[i][j]:
                            indegree[ni][nj] += 1

        # 入度为 0 的点入队
        q = deque()

        for i in range(n):
            for j in range(m):
                if indegree[i][j] == 0:
                    q.append((i, j))

        ans = 0

        # BFS 分层
        while q:
            size = len(q)
            ans += 1

            for _ in range(size):
                i, j = q.popleft()

                for di, dj in directions:
                    ni = i + di
                    nj = j + dj

                    if ni < 0 or ni >= n or nj < 0 or nj >= m:
                        continue

                    if matrix[ni][nj] <= matrix[i][j]:
                        continue

                    indegree[ni][nj] -= 1

                    if indegree[ni][nj] == 0:
                        q.append((ni, nj))

        return ans
```
