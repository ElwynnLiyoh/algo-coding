## 0-1 背包

**核心特征**：每个物品最多只能选择一次：选 / 不选。

### 二维DP

**dp定义**：`dp[i][j]`：只考虑前 `i` 个物品，背包容量为 `j` 时能够获得的最大价值。
**状态转移**：
$$
dp[i][j]=max(dp[i−1][j],dp[i−1][j−weight[i]]+value[i])
$$

### 一维DP

**dp定义**：`dp[j]`：当前已经处理过的物品中，容量为 `j` 时的最大价值。
**状态转移**：
$$
dp[j]=max(dp[j],dp[j−weight[i]]+value[i])
$$


时间复杂度： $O()$
空间复杂度： $O()$

```python
def knapsack(weights: list[int], values: list[int], capacity: int) -> int:
    dp = [0] * (capacity + 1)

    for i in range(len(weights)):
        for j in range(capacity, weights[i] - 1, -1):
            dp[j] = max(
                dp[j],
                dp[j - weights[i]] + values[i]
            )

    return dp[capacity]
```

**为什么从大到小？**

例如处理`dp[5]`时，需要的`dp[3]`是**处理当前物品之前的状态**，所以当前物品不会被重复使用。


## 完全背包

每种物品可以选无限次。

### 二维DP

**dp定义**：`dp[i][j]`：只考虑前 `i` 个物品，背包容量为 `j` 时能够获得的最大价值。
**状态转移**：
$$
dp[i][j]=max(dp[i−1][j],dp[i][j−weight[i]]+value[i])
$$
### 一维DP

**dp定义**：`dp[j]`：当前已经处理过的物品中，容量为 `j` 时的最大价值。
**状态转移**：
$$
dp[j]=max(dp[j],dp[j−weight[i]]+value[i])
$$
因为可以重复使用，从小到大遍历。

```python
def complete_knapsack(weights: list[int], values: list[int], capacity: int) -> int:
    dp = [0] * (capacity + 1)

    for i in range(len(weights)):
        weight = weights[i]
        value = values[i]

        # 完全背包：容量从小到大遍历
        # 这样 dp[j - weight] 可能已经使用过当前物品，
        # 因此可以再次选择当前物品。
        for j in range(weight, capacity + 1):
            dp[j] = max(dp[j], dp[j - weight] + value)

    return dp[capacity]
```
