## 目标和

题号：[LC494](https://leetcode.cn/problems/target-sum/description/)
描述：给你一个非负整数数组 `nums` 和一个整数 `target` 。
向数组中的每个整数前添加 `'+'` 或 `'-'` ，然后串联起所有整数，可以构造一个 **表达式** ：
- 例如，`nums = [2, 1]` ，可以在 `2` 之前添加 `'+'` ，在 `1` 之前添加 `'-'` ，然后串联起来得到表达式 `"+2-1"` 。
返回可以通过上述方法构造的、运算结果等于 `target` 的不同 **表达式** 的数目。

### DP

**状态定义**： `dp[i]`表示凑出 j 一共有多少种方法
**状态转移**：
$$
dp[j] += dp[j - num]
$$
原来凑出 j 的方案+选择当前 num 后，从 j-num 转移过来的方案

**初始条件**：

时间复杂度： $O()$
空间复杂度： $O()$

```python
class Solution:
    def findTargetSumWays(self, nums: list[int], target: int) -> int:
        total = sum(nums)

        # 所有数字取正时绝对值最大为 total
        if abs(target) > total:
            return 0

        # P = (total + target) / 2 必须是整数
        if (total + target) % 2 != 0:
            return 0

        positive_sum = (total + target) // 2

        # dp[j]：凑出 j 的方案数
        dp = [0] * (positive_sum + 1)
        dp[0] = 1

        for num in nums:
            # 0/1 背包：每个数字只能使用一次
            for j in range(positive_sum, num - 1, -1):
                dp[j] += dp[j - num]

        return dp[positive_sum]
```


### 回溯

时间复杂度： $O(2^n)$
空间复杂度： $O(n)$

```python
class Solution:
    def findTargetSumWays(self, nums: list[int], target: int) -> int:
        ans = 0

        def dfs(i: int, total: int) -> None:
            nonlocal ans

            if i == len(nums):
                if total == target:
                    ans += 1
                return

            # 当前数字选择 +
            dfs(i + 1, total + nums[i])

            # 当前数字选择 -
            dfs(i + 1, total - nums[i])

        dfs(0, 0)
        return ans
```
