## 树的直径

题号：[LC543](https://leetcode.cn/problems/diameter-of-binary-tree)
描述：找最长路径
思路：最长路径端点一定在两个叶子节点。
在当前节点「拐弯」的直径长度=左子树的最长链+右子树的最长链+2（+2是连接两个孩子）
返回给父节点的是以当前节点为根的子树的最长链=max(左最长链，右最长链)+1

本质是后序遍历所有子树并计算经过子树根节点的最长路径取max。

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    # 写法一
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def dfs(node):
            if not node:
                return -1
            l_len = dfs(node.left)
            r_len = dfs(node.right)
            nonlocal ans
            # 叶子节点 -1-1+2刚好是0
            ans = max(ans, l_len + r_len + 2)
            return max(l_len, r_len) + 1

        dfs(root)
        return ans
    
    # 写法二（更简洁）：左右长度直接+1
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def dfs(node):
            if not node:
                return -1
            l_len = dfs(node.left) + 1
            r_len = dfs(node.right) + 1
            nonlocal ans
            # 叶子节点刚好是 -1-1+2刚好是0
            ans = max(ans, l_len + r_len)
            return max(l_len, r_len)

        dfs(root)
        return ans
```
