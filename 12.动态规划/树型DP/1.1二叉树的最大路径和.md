## 二叉树的最大路径和

题号：[LC124](https://leetcode.cn/problems/binary-tree-maximum-path-sum)
描述：找到一条路径，使得和最大。
思路：

在树的直径上修改就能得到最大路径和。

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def maxPathSum(self, root: TreeNode | None) -> int:
        # 初始化
        ans = -inf

        def dfs(node):
            if not node:
                return 0
            # 左右节点最大路径和
            l_val = dfs(node.left)
            r_val = dfs(node.right)
            nonlocal ans
            # 以当前节点为捌点的最大路径和
            ans = max(ans, l_val + r_val + node.val)
            # 可能有负数，需要和0比较大小
            return max(max(l_val, r_val) + node.val, 0)

        dfs(root)
        return ans
```
