## 不同路径的数目1

题号： BM67， LC62
描述： 一个机器人在m×n大小的地图的左上角（起点）。机器人每次可以向下或向右移动。机器人要到达地图的右下角（终点）。可以有多少种不同的路径从起点走到终点？
思路： 
$$
dp[i][j]=dp[i−1][j]+dp[i][j−1]
$$
时间复杂度： $O(nm)$
空间复杂度： $O(nm)$

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:

        dp = [[1]*m for _ in range(n)]

        for i in range(1, n):
            for j in range(1, m):
                dp[i][j] = dp[i-1][j] + dp[i][j-1]

        return dp[n-1][m-1]
```

压缩（**最优解**）
时间 O(m*n)
空间 O(m)

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:

        dp = [1] * m

        for i in range(1, n):
            for j in range(1, m):
                # 累加的每一行都压缩到了一维数组中
                dp[j] += dp[j-1]

        return dp[-1]
```



DFS

时间复杂度： $O(nm)$
空间复杂度： $O(nm)$，还有递归栈O(m+n)
必须记忆化，否则时间复杂度将达到$O(2^{n+m})$，C也会超时。
注意这里和正推 DP 不一样：

二维 DP：`dp[i][j] = 到达(i,j)的方法数`
DFS memo：`dfs(i,j) = 从(i,j)到终点的方法数`
方向相反。
$$
dfs(i,j)=dfs(i+1,j)+dfs(i,j+1)
$$

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        memo = {}
        def dfs(i, j):
            # 到达终点
            if i == n-1 and j == m-1:
                return 1

            # 越界
            if i >= n or j >= m:
                return 0
            # 已经计算过
            if (i, j) in memo:
                return memo[(i, j)]

            # 状态转移
            ans = dfs(i+1, j) + dfs(i, j+1)
            # 记录结果
            memo[(i, j)] = ans

            return ans

        return dfs(0, 0)
```
