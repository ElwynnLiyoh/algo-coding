## 2.0最长回文子串

题号： BM73，LC5
描述： 对于长度为n的一个字符串A（仅包含数字，大小写英文字母），请设计一个高效算法，计算其中最长回文子串的长度。​
**状态定义**：`dp[i][j]`表示字符串 i 到 j 是否为回文。
**状态转移**：
$$
dp[i][j]=(A[i]==A[j])∧dp[i+1][j−1]
$$
**初始条件**：`False`
时间复杂度： $O(n^2)$
空间复杂度： $O(n^2)$

```python
class Solution:
    def getLongestPalindrome(self, A):
        n = len(A)
        dp = [[False]*n for _ in range(n)]

        max_len = 1
        for i in range(n-1,-1,-1):
            for j in range(i,n):
                if A[i] == A[j] and (j-i <= 2 or dp[i+1][j-1]):
                    dp[i][j] = True
                    max_len = max(max_len,j-i+1)

        return max_len
```
为什么需要`j-i<=2`? 

- 因为后面有`dp[i+1][j-1]`, 在边界会溢出。

- 优化：`len=j-i+1`, `j-i<=2`等价于`len<=3`。`len==3`时只需要`A[i]==A[j]`, `len<=2`时天然回文。



LC版需要反回子串，多记录一个起始位置即可

```python
class Solution:
    def longestPalindrome(self, A: str) -> str:
        n = len(A)
        dp = [[False] * n for _ in range(n)]

        max_len = 1
        start = 0
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if A[i] == A[j] and (j - i <= 2 or dp[i + 1][j - 1]):
                    dp[i][j] = True
                    if j - i + 1 > max_len:
                        max_len = j - i + 1
                        start = i

        return A[start : start + max_len]
```



### 中心扩展

时间复杂度： $O(n^2)$
空间复杂度： $O(1)$

```python
class Solution:
    def getLongestPalindrome(self, A: str) -> int:
        n = len(A)
        if n == 0:
            return 0

        def expand(left, right):
            while left >= 0 and right < n and A[left] == A[right]:
                left -= 1
                right += 1

            # 跳出时：
            # left,right已经多走了一步
            return right - left - 1

        ans = 1
        for i in range(n):
            # 奇数长度
            ans = max(ans, expand(i, i))
            # 偶数长度
            ans = max(ans, expand(i, i+1))

        return ans
```



返回子串，函数修改成返回下标

```python
class Solution:
    def longestPalindrome(self, A: str) -> str:
        n = len(A)
        if n == 0:
            return 0

        def expand(left, right):
            while left >= 0 and right < n and A[left] == A[right]:
                left -= 1
                right += 1

            # 跳出时：
            # left,right已经多走了一步
            return left + 1, right - 1

        start = 0
        end = 0
        for i in range(n):
            # 奇数长度
            l1, r1 = expand(i, i)
            # 偶数长度
            l2, r2 = expand(i, i + 1)

            if r1 - l1 > end - start:
                start, end = l1, r1
            if r2 - l2 > end - start:
                start, end = l2, r2

        return A[start: end + 1]
```
