## 买卖股票的最好时机4

题号： DP33,  LC1883
描述： 3的推广

写法一的dp定义
```
dp[0] = 未操作
dp[1] = 第1次买
dp[2] = 第1次卖
... 
dp[2k] = 第k次卖
```
实际上表示：
> **已经进入/完成第 k 次卖出的状态**

注意写法二的dp定义不同，是**至多`j`次交易**而不是**恰好完成`j`次交易**，因此返回的`sell[k]` 的状态实际上会继承“不进行第 k 次交易”的结果，所以没有法一的取max问题。

时间复杂度： $O(n)$
空间复杂度： $O(kn)$

```python
# 写法一
class Solution:
    def maxProfit(self, k: int, prices: List[int]) -> int:
        n = len(prices)
        if n <= 1 or k == 0:
            return 0
        
        k = min(k, n // 2)

        neg_inf = float("-inf")
        dp = [[neg_inf] * (2 * k + 1) for _ in range(n)]

        dp[0][0] = 0
        dp[0][1] = -prices[0]

        for i in range(1, n):
            dp[i][0] = dp[i - 1][0]
            for j in range(1, 2 * k + 1):
                dp[i][j] = max(
                    dp[i - 1][j], 
                    dp[i - 1][j - 1] + (-1 if j % 2 else 1) * prices[i]
                )

        # return dp[n - 1][2 * k]
        # 交易次数可以小于k，故应该取所有卖出状态的最大值
        return max(dp[n - 1][j] for j in range(0, 2 * k + 1, 2))

# 写法二
class Solution:
    def maxProfit(self, k: int, prices: list[int]) -> int:
        n = len(prices)
        if n <= 1 or k == 0:
            return 0

        neg_inf = float("-inf")
        
		# buy[j]  = 至多进行 j 次交易，目前持有股票的最大利润
		# sell[j] = 至多进行 j 次交易，目前不持有股票的最大利润
		k = min(k, n // 2)
        buy = [neg_inf] * (k + 1)
        sell = [0] * (k + 1)

        for price in prices:
            for j in range(1, k + 1):
                buy[j] = max(
                    buy[j],
                    sell[j - 1] - price
                )

                sell[j] = max(
                    sell[j],
                    buy[j] + price # 使用的是同一天更新后的buy[j]。允许今天买，今天卖。
                )

        return sell[k]
```
