## ​正则表达式匹配

题号： BM76, LC10
描述： 请实现一个函数用来匹配包括'.'和'*'的正则表达式。1.模式中的字符'.'表示任意一个字符 2.模式中的字符'*'表示它前面的字符可以出现任意次（包含0次）。

**状态定义**：`dp[i][j]`表示：字符串 `s` 的前 `i` 个字符，是否能匹配模式 `p` 的前 `j` 个字符。

**初始条件**：空字符串和空模式：`dp[0][0] = True`

时间复杂度： $O(nm)$

> 因为 `i,j` 表示的是前x个字符，故`s[i-1], p[j-1]`才是当前比较的字符。

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:

        n = len(s)
        m = len(p)

        dp = [[False]*(m+1) for _ in range(n+1)]
        dp[0][0] = True

        # 空字符串匹配 a*b*c*
        for j in range(2, m+1):
            if p[j-1] == '*':
                dp[0][j] = dp[0][j-2]

        for i in range(1, n+1):
            for j in range(1, m+1):
                if p[j-1] != '*':
                    # 普通字符 或 .
                    if p[j-1] == '.' or p[j-1] == s[i-1]:
                        dp[i][j] = dp[i-1][j-1]
                else:
                    # * 匹配0次（不使用或p[j-2]!=s[i-1]）
                    dp[i][j] = dp[i][j-2]
                    # * 匹配多次
                    if p[j-2] == '.' or p[j-2] == s[i-1]:
                        dp[i][j] |= dp[i-1][j]

        return dp[n][m]
```

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        n = len(s)
        m = len(p)

        # dp[j]表示：
        # 当前处理到s的某个位置时，s的前i个字符是否匹配p的前j个字符
        dp = [False] * (m + 1)
        dp[0] = True

        # 初始化空字符串匹配模式：
        # 只有a*b*c*这种形式可以匹配空串
        for j in range(2, m + 1):
            if p[j - 1] == '*':
                dp[j] = dp[j - 2]

        for i in range(1, n + 1):
            # 保存dp[j-1]的旧值，即二维中的dp[i-1][j-1]
            prev = dp[0]

            # 当前行第一列：
            # 非空字符串无法匹配空模式
            dp[0] = False

            for j in range(1, m + 1):
                # 保存更新前的dp[j]
                # 它代表二维中的dp[i-1][j]
                temp = dp[j]

                if p[j - 1] != '*':
                    # 普通字符或'.'
                    if p[j - 1] == '.' or p[j - 1] == s[i - 1]:
                        dp[j] = prev
                    else:
                        dp[j] = False

                else:
                    # '*'匹配0次：
                    # 去掉前面的字符和*
                    dp[j] = dp[j - 2]

                    # '*'匹配1次或多次：
                    # 当前字符匹配'*'前面的字符
                    if p[j - 2] == '.' or p[j - 2] == s[i - 1]:
                        # dp[j]之前的状态是：
                        # dp[i-1][j]
                        dp[j] |= temp

                # 更新左上角
                prev = temp

        return dp[m]
```
