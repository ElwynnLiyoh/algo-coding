## 最长公共子串

题号： BM66
描述：   "1AB2345CD"和"12345EF"的最长公共子串是”2345“
思路： 与最长公共子序列的区别在于子串需要连续

**DP状态定义**：`dp[i][j]`表示以 `str1[i-1]` 和 `str2[j-1]` 作为结尾的最长公共子串长度。

**状态转移**：

如果前两个字符相同，则
$$
dp[i][j]=dp[i−1][j−1]+1
$$
如果不同，意味着以这两个字符结尾的公共子串长度重置为 0。
$$
dp[i][j]=0
$$


时间复杂度： $O(nm)$
空间复杂度： $O(nm)$

```python
class Solution:
    def LCS(self, str1: str, str2: str) -> str:
        n = len(str1)
        m = len(str2)

        dp = [[0] * (m + 1) for _ in range(n + 1)]

        max_len = 0
        end = 0

        for i in range(1, n + 1):
            for j in range(1, m + 1):

                if str1[i - 1] == str2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1

                    if dp[i][j] > max_len:
                        max_len = dp[i][j]
                        end = i
                else:
                    dp[i][j] = 0
                    
        # 根据dp定义，不需要end-1
        return str1[end - max_len:end]
```



**空间优化**

空间复杂度： $O(m)$

**必须从右往左**： 二维DP`dp[i][j]`需要`dp[i-1][j-1]`,  如果从左往右，到了`j=2`时，`dp[j-1]`已经被修改了，不再是`dp[i-1][j-1]`而是`dp[i][j-1]`。子序列可以从左往右，是用 `prev` 保存了即将被覆盖的左上角。


```python
class Solution:
    def LCS(self, str1: str, str2: str) -> str:
        n = len(str1)
        m = len(str2)

        dp = [0] * (m + 1)

        max_len = 0
        end = 0

        for i in range(1, n + 1):
            # 必须从右向左
            for j in range(m, 0, -1):
                if str1[i - 1] == str2[j - 1]:
                    dp[j] = dp[j - 1] + 1
                    if dp[j] > max_len:
                        max_len = dp[j]
                        end = i

                else:
                    dp[j] = 0

        return str1[end - max_len:end]
```



最便捷的写法：

```python
class Solution:
    def LCS(self, str1: str, str2: str) -> str:
        # 让str1为较长的字符串
        if len(str1) < len(str2):
            str1, str2 = str2, str1
        res = ""
        max_len = 0
        # 遍历str1的长度
        for i in range(len(str1)):
            sub = str1[i - max_len : i + 1]
            # 查找是否存在
            if sub in str2:
                res = sub
                max_len += 1
        return res
```



**比较**

|          | 最长公共子序列   | 最长公共子串         |
| -------- | ---------------- | -------------------- |
| 是否连续 | ❌ 不要求         | ✅ 必须连续           |
| 相等     | `dp[i-1][j-1]+1` | `dp[i-1][j-1]+1`     |
| 不相等   | `max(上, 左)`    | **`0`**              |
| 答案位置 | `dp[n][m]`       | **整个 DP 表最大值** |
| 一维优化 | `O(m)`           | `O(m)`               |
| 核心     | 可以跳过字符     | 不能断开             |
