## 编辑距离

题号： BM75
描述： 给定两个字符串 str1 和 str2 ，请你算出将 str1 转为 str2 的最少操作数。
你可以对字符串进行3种操作：1.插入一个字符 2.删除一个字符 3.修改一个字符。

## 二维DP

**状态定义**：`dp[i][j]`表示：将 str1 的前 i 个字符转换成 str2 的前 j 个字符，所需要的最少操作次数。
**状态转移**：
$$
dp[i][j]=\begin{cases}dp[i][j]=dp[i−1][j−1] & str1[i-1] = str2[j-1] \\
min(dp[i−1][j]+1,dp[i][j−1]+1,dp[i−1][j−1]+1) & str1[i-1] \ne str2[j-1]\end{cases}
$$
**初始条件**：如果`str1==""`, 则`dp[0][j]=j`; 如果`str2==""`, 则`dp[i][0]=i`;

时间复杂度： $O(nm)$
空间复杂度： $O(nm)$

```python
class Solution:
    def minDistance(self, str1: str, str2: str) -> int:
        n = len(str1)
        m = len(str2)

        dp = [[0]*(m+1) for _ in range(n+1)]

        # 初始化
        for i in range(n+1):
            dp[i][0] = i
        for j in range(m+1):
            dp[0][j] = j


        for i in range(1, n+1):
            for j in range(1, m+1):
                if str1[i-1] == str2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = min(
                        dp[i-1][j] + 1,      # 删除
                        dp[i][j-1] + 1,      # 插入
                        dp[i-1][j-1] + 1    # 修改
                    )

        return dp[n][m]
```

### 一维DP

**状态定义**：`dp[j]` 表示当前处理到 `str1` 的某一个位置时，`str1` 前 i 个字符转换成 `str2` 前 j 个字符的最少操作数。

| **一维变量**     | **二维含义**       | **对应** |
| ------------ | -------------- | ------ |
| `dp[j]`（更新前） | `dp[i-1][j]`   | 原来的上   |
| `dp[j-1]`    | `dp[i][j-1]`   | 原来的左   |
| `prev`       | `dp[i-1][j-1]` | 原来的左上  |
| 更新后的 `dp[j]` | `dp[i][j]`     |        |

空间复杂度： $O(m)$
```python
class Solution:
    def minDistance(self, str1, str2):

        n = len(str1)
        m = len(str2)

        dp = list(range(m+1))

        for i in range(1, n+1):
            prev = dp[0]    # 上一行的左上角
            dp[0] = i       # 新的一行，空串

            for j in range(1, m+1):
                temp = dp[j]  # 保存起来，后面会被覆盖
                if str1[i-1] == str2[j-1]:
                    dp[j] = prev
                else:
                    dp[j] = min(
                        dp[j] + 1,      # 删除
                        dp[j-1] + 1,    # 插入
                        prev + 1        # 修改
                    )

                prev = temp

        return dp[m]
```
### DFS

从`str1`删除字符等价于从`str2`插入字符

时间复杂度： $O(nm)$
空间复杂度： $O(nm)$, 缓存nm

```python
from functools import cache
class Solution:
    def editDistance(self, str1: str, str2: str) -> int:
        n = len(str1)
        m = len(str2)

        @cache
        def dfs(i, j):
            if i < 0:
                return m + 1
            if j < 0:
                return n + 1
            if str1[i] == str2[j]:
                return dfs(i - 1, j - 1)
            else:
                # 删除、插入、修改
                return min(dfs(i - 1, j), dfs(i, i - 1), dfs(i - 1, j - 1)) + 1

        return dfs(n - 1, m - 1)
```
