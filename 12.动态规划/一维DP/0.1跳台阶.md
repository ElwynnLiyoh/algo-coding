## 跳台阶

题号： BM63
描述： 一只青蛙一次可以跳上1级台阶，也可以跳上2级。求该青蛙跳上一个 n 级的台阶总共有多少种跳法（先后次序不同算不同的结果）。

### 法一：递归

思路： 从第n个台阶进行下台阶，下一步有2中可能，一种走到第n-1个台阶，一种是走到第n-2个台阶。所以f[n] = f[n-1] + f[n-2]. 那么初始条件了，f[0] = f[1] = 1。 所以就变成了：f[n] = f[n-1] + f[n-2], 初始值f[0]=1, f[1]=1，目标求f[n] 看到公式很亲切，代码秒秒钟写完。
时间复杂度： $O(2^n)$
空间复杂度： $O()$ 递归栈空间

这就和斐波那契一样

```go
func jumpFloor(number int) int {
    if number <= 1 {
    		return 1
    }
    return jumpFloor(number-1) + jumpFloor(number-2)
}
```

类似的，使用记忆化递归可以省很多重复计算

```python
class Solution:
    def __init__(self):
        self.memo = {}

    def jumpFloor(self, number: int) -> int:
        # 状态转移方程：f(n) = f(n-1) + f(n-2)
        # 初始条件：f1=1, f2=2
        if number <= 2:
            return number

        if number not in self.memo:
            self.memo[number] = self.jumpFloor(number - 1) + self.jumpFloor(number - 2)
        return self.memo[number]
```



### 法二：动态规划

时间复杂度： $O(n)$
空间复杂度： $O(1)$ 

Python

```python
def jumpFloor(self, number: int) -> int:
        # 状态转移方程：f(n) = f(n-1) + f(n-2)
        # 初始条件：f1=1, f2=2
        if number <= 2:
            return number
        a, b = 1, 2
        for _ in range(3, number + 1):
            a, b = b, a + b
        return b
```

go

```go
func jumpFloor(number int) int {
  	// 前两次单独处理
    if number <= 2 {
      	return number
    }
    a, b := 1, 2 // 前两次状态
    var c int		// c表示当前dp
    for i := 3; i <= number; i++ {
        c = a + b
        a = b
        b = c
    }
    return c
}
```
