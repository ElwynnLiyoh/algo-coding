## 最长递增子序列

题号： BM71
描述： 给定一个长度为 n 的数组 arr，求它的最长严格上升子序列的长度。

### 记忆化递归

时间复杂度： $O(n^2)$, 两层for循环
空间复杂度： $O(n)$

```python
class Solution:
    def LIS(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 0:
            return 0

        memo = {}

        def L(i):
            if i == n - 1:
                return 1
            if i in memo:
                return memo[i]
            max_len = 1
            for j in range(i + 1, n):
                if arr[j] > arr[i]:
                    max_len = max(max_len, L(j) + 1)
            memo[i] = max_len
            return max_len

        max_len = 1
        for i in range(n):
            ret = L(i)
            if ret > max_len:
                max_len = ret
        return max_len
        # return max(L(i) for i in range(n)) # 简化成一行
```

### 迭代

#### 法一

时间复杂度： $O(n^2)$,
空间复杂度： $O(n)$

**状态定义**： dp[i]是以i起始的上升子序列长度

**状态转移**：
$$
dp[i]=max(dp[i],dp[i+1])
$$
**初始条件**： `dp[-1]=1`，所以应该从后往前处理

```python
class Solution:
    def LIS(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 0:
            return 0

        L = [1] * n

        # 从后往前
        for i in reversed(range(n)):
            for j in range(i + 1, n):
                if arr[j] > arr[i]:
                    L[i] = max(L[i], L[j] + 1)
        return max(L)
```


#### 法二

时间复杂度： $O(n^2)$,
空间复杂度： $O(n)$

**状态定义**： dp[i]是以arr[i]为结尾的最长严格上升子序列的长度。

**状态转移**：
$$
dp[i]=max(dp[i],dp[i-1])
$$
**初始条件**： `dp[0]=1`，所以应该从前往后处理

注意状态定义和初始条件的不同

```python
class Solution:
    def LIS(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 0:
            return 0

        L = [1] * n

        # 从前往后
        for i in range(1, n):
            for j in range(i):
                if arr[j] < arr[i]:
                    L[i] = max(L[i], L[j] + 1)
        return max(L)
```
