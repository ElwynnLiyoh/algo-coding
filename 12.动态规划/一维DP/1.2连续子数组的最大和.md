## 连续子数组的最大和

题号： BM72，LC53
描述： 给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**状态定义**：`dp[i]`表示以`array[i]`为结尾的连续子数组最大和。
**状态转移**：
$$
 dp[i] = max(dp[i-1]+array[i], array[i])
$$
**初始条件**：`dp[0]=array[0]`
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def FindGreatestSumOfSubArray(self, array: List[int]) -> int:
        n = len(array)
        dp = [array[0]] * n
        for i in range(1, n):
            dp[i] = max(dp[i - 1] + array[i], array[i])
 
        return max(dp)
```



**优化**

`dp[i]`只依赖于`dp[i-1]`和当前处理的数字，故无需保存整个数组

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
class Solution:
    def FindGreatestSumOfSubArray(self, array: List[int]) -> int:
        n = len(array)
        max_sum = cur_sum = array[0]
        for i in range(1, n):
            # 是积累下来的值更大还是当前值更大
            cur_sum = max(array[i] + cur_sum, array[i])
            if cur_sum > max_sum:
                max_sum = cur_sum
        return max_sum
```
