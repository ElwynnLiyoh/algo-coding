## 斐波那契数列

题号： BM62，[LC509](https://leetcode.cn/problems/fibonacci-number/)
描述： 1,1,2,3,5
思路： 


### 迭代（标准解法）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
def fib(self, n: int) -> int:
    if n <= 1:
        return n

    pre2, pre1 = 0, 1
    for i in range(2, n + 1):
        pre2, pre1 = pre1, pre1 + pre2
    return pre1
```


### 递归解法

存在大量重复计算

时间复杂度： $O(2^n)$
空间复杂度： $O(n)$

```python
def fib(self, n: int) -> int:
    if n <= 1:
        return n

    return self.fib(n - 1) + self.fib(n - 2)
```



### 记忆化递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$ + 递归栈

```python
class Solution:
    memo = {}
    #@cache # 最简单
    def fib(self, n: int) -> int:
        if n <= 1:
            return n

        if n not in self.memo:
            self.memo[n] = self.fib(n - 1) + self.fib(n - 2)

        return self.memo[n]
```



### 其它

矩阵快速幂 和 Fast Doubling（快速倍增法）

时间复杂度： $O(\log n)$

```python
def fib(n):
    if n == 0:
        return 0, 1

    a, b = fib(n // 2)

    c = a * (2 * b - a)
    d = a * a + b * b

    if n % 2 == 0:
        return c, d
    else:
        return d, c + d

def Fibonacci(n):
    return fib(n)[0]
```
