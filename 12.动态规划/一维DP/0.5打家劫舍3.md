## 打家劫舍3

题号： LC337
描述： 二叉树打家劫舍。每个节点代表一间房子，节点值是现金。不能同时偷直接相连的两个节点，求最多能偷多少钱。

**状态定义**： `(rob, not_rob)`表示偷与不偷当前节点
**状态转移**：
$$
\begin{cases}
rob &= node.val + left\_not\_rob + right\_not\_rob \\
not\_rob &= max(left\_rob, left\_not\_rob) \
        + max(right\_rob, right\_not\_rob) \end{cases}
$$
**初始条件**：

**为什么必须后序遍历？** 因为计算当前节点需要左右子树的答案。

时间复杂度： $O(n)$
空间复杂度： $O(h)$, 如果是最坏的链状树，`h = n`；如果是平衡二叉树，`h = O(log n)`。

```python
class Solution:
    def rob(self, root: TreeNode) -> int:
        def dfs(node: TreeNode) -> tuple[int, int]:
            if node is None:
                return 0, 0

            # 后序遍历，先计算左右子树
            left_rob, left_not_rob = dfs(node.left)
            right_rob, right_not_rob = dfs(node.right)

            # 偷当前节点：左右孩子都不能偷
            rob = node.val + left_not_rob + right_not_rob

            # 不偷当前节点：左右孩子分别选择最优方案
            not_rob = max(left_rob, left_not_rob) \
                    + max(right_rob, right_not_rob)

            return rob, not_rob

        # rob_root, not_rob_root = dfs(root)
        # return max(rob_root, not_rob_root)
        return max(dfs(root))
```
