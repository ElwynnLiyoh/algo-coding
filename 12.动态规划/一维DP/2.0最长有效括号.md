## 最长有效括号

题号： BM77，LC32
描述： 给出一个长度为 n 的，仅包含字符 '(' 和 ')' 的字符串，计算最长的格式正确的括号子串的长度。
例1: 对于字符串 "(()" 来说，最长的格式正确的子串是 "()" ，长度为 2 .  
例2：对于字符串 ")()())" , 来说, 最长的格式正确的子串是 "()()" ，长度为 4 .

### DP

**状态定义**：`dp[i]`表示： 以 `s[i]` 这个字符**结尾**的最长有效括号子串长度。

**初始条件**：`dp = [0] * n`

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return 0

        # dp[i]：以 s[i] 结尾的最长有效括号子串长度
        dp = [0] * n
        ans = 0

        for i in range(1, n):
            # 只有 ')' 才可能作为有效括号串的结尾
            if s[i] == ')':
                if s[i - 1] == '(':
                    # 情况1：直接形成 "()"
                    # 如果 i >= 2，前面还可能有一段有效括号
                    dp[i] = 2
                    if i >= 2:
                        dp[i] += dp[i - 2]

                else:
                    # 情况2：s[i-1] == ')'
                    # dp[i-1] 是前面连续有效括号的长度
                    prev_len = dp[i - 1]

                    # 跳过前面的有效括号后，
                    # 再往前一个位置就是可能与 s[i] 匹配的 '('
                    j = i - prev_len - 1

                    if j >= 0 and s[j] == '(':
                        # 当前 ')' 与 s[j] 匹配
                        dp[i] = prev_len + 2

                        # 如果匹配的 '(' 前面还有一段有效括号，
                        # 也要把它接起来
                        # 例如："()(())"
                        if j >= 1:
                            dp[i] += dp[j - 1]

                ans = max(ans, dp[i])

        return ans
```

### 左右遍历

以从左到右为例：
`(` 过多并不一定是问题，因为后面还可能出现 `)` 来匹配它；  
`)` 过多则一定已经出问题，因为后面再出现 `(` 也无法补救前面那个多出来的 `)`。

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        ans = 0
        left = right = 0

        # 从左到右：处理 ')' 过多的情况
        for c in s:
            if c == '(':
                left += 1
            else:
                right += 1

            if left == right:
                ans = max(ans, left + right)
            elif right > left:
                left = right = 0

        left = right = 0

        # 从右到左：处理 '(' 过多的情况
        for c in reversed(s):
            if c == '(':
                left += 1
            else:
                right += 1

            if left == right:
                ans = max(ans, left + right)
            elif left > right:
                left = right = 0

        return ans
```


### 栈

**核心思路**： 栈里**不存括号，而是存下标**。
> 栈顶始终表示当前有效括号区间不能跨越的最后一个位置。

**初始化**： `stack=[-1]`。
例如：`()`。处理到 `)` 时：`stack = [-1, 0]`，弹出 `0` 后：`i - stack[-1] = 1 - (-1) = 2`

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]
        ans = 0

        for i, c in enumerate(s):
            if c == '(':
                # 保存左括号下标，等待后面的 ')' 匹配
                stack.append(i)
            else:
                # 当前 ')' 尝试匹配最近的 '('
                stack.pop()

                if stack:
                    # 栈顶是当前有效子串的左边界
                    ans = max(ans, i - stack[-1])
                else:
                    # 没有可以作为边界的下标
                    # 当前 ')' 不可能属于后面的有效括号
                    stack.append(i)

        return ans
```
