## 打家劫舍2

题号： BM79, LC213
描述： 环型打家劫舍

**拆分成两个子问题**

不偷第一家，让DP决定是否偷最后一家;
不偷最后一家，让DP决定是否偷第一家。

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
# 法一： 迭代
class Solution:
    def rob(self, nums: List[int]) -> int:
        if len(nums) <= 1:
            return sum(nums)

        return max(self.rob_range(nums[1:]), self.rob_range(nums[:-1]))

    def rob_range(self, nums: List[int]) -> int:
        pre2 = pre1 = 0
        for money in nums:
            pre2, pre1 = pre1, max(pre1, pre2 + money)
        return pre1

     
# 法二： DFS记忆化递归
class Solution:
    def rob(self, nums: List[int]) -> int:
        if len(nums) <= 1:
            return sum(nums)

        memo1 = {}
        memo2 = {}

        def dfs(i: int, nums: List[int], memo):
            if i >= len(nums):
                return 0
            if i in memo:
                return memo[i]

            skip = dfs(i + 1, nums, memo)
            take = nums[i] + dfs(i + 2, nums, memo)
            memo[i] = max(skip, take)
            return memo[i]

        return max(dfs(0, nums[1:], memo1), dfs(0, nums[:-1], memo2))
```
