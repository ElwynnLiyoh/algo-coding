## 数字翻译成字符串

题号： BM69
描述： 有一种将字母编码成数字的方式：'a'->1, 'b->2', ... , 'z->26'。现在给一串数字，返回有多少种可能的译码结果。

**状态定义**： `dp[i]`表示前`i`个字符组成的数字串，有多少种译码方式。
**状态转移**：
$$
dp[i]=\begin{cases}+dp[i−1] &单字符有效\\+ dp[i−2]&双字符有效\end{cases}
$$

**初始化**：`dp[0]=1`

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def solve(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0

        dp = [0] * (n + 1)
        dp[0] = 1
        # 第一位不能为0
        if s[0] != '0':
            dp[1] = 1

        for i in range(2, n + 1):
            # 单字符
            if s[i-1] != '0':
                dp[i] += dp[i-1]

            # 双字符
            num = int(s[i-2:i])
            if 10 <= num <= 26:
                dp[i] += dp[i-2]

        return dp[n]
```

空间优化
由于`dp[i]`只依赖`dp[i-1]`和`dp[i-2`，所以压缩，类似于斐波那契。

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
class Solution:
    def solve(self, s: str) -> int:

        if not s or s[0] == '0':
            return 0

        prev2 = 1   # dp[i-2]
        prev1 = 1   # dp[i-1]

        for i in range(1, len(s)):
            cur = 0
            # 单字符
            if s[i] != '0':
                cur += prev1

            # 双字符
            num = int(s[i-1:i+1])
            if 10 <= num <= 26:
                cur += prev2

            prev2 = prev1
            prev1 = cur

        return prev1
```



这题和跳台阶的关系：

跳台阶：

```
dp[i]=dp[i-1]+dp[i-2]
```

译码：

```
当前字符有效:
    加 dp[i-1]

当前两个字符有效:
    加 dp[i-2]
```
