## 旋转矩阵

题号： BM99
描述：
有一个NxN整数矩阵，请编写一个算法，将矩阵顺时针旋转90度。
给定一个NxN的矩阵，和矩阵的阶数N,请返回旋转后的NxN矩阵。

### 找到数学关系

时间复杂度： $O(n^2)$
空间复杂度： $O(n^2)$

```python
def rotateMatrix(self, mat: List[List[int]], n: int) -> List[List[int]]:
    ans = [[0] * n for _ in range(n)]

    for i in range(n):
        for j in range(n):
            ans[j][n - 1 - i] = mat[i][j]

    return ans
```

### 原地修改
时间复杂度： $O(n^2)$
空间复杂度： $O(1)$

1. **矩阵转置**
2. **每一行翻转**

例如：

```
1 2 3       1 4 7       7 4 1
4 5 6  →    2 5 8   →   8 5 2
7 8 9       3 6 9       9 6 3

原矩阵        转置         每行翻转
```

```python
def rotateMatrix(self, mat: List[List[int]], n: int) -> List[List[int]]:
    # 转置
    for i in range(n):
      	for j in range(i):	# 遍历左下三角
        #for j in range(i + 1, n): # 遍历右上三角
            mat[i][j], mat[j][i] = mat[j][i], mat[i][j]

    # 每一行翻转
    for row in mat:
        row.reverse()

    return mat
```
