## 二叉树的双色标记遍历

**双色标记法（Color Marking）**，它可以用统一的方式实现二叉树的**前序、中序、后序遍历**，核心是给节点设置：

- `0`：白色，表示**第一次遇到，还没有处理**
- `1`：灰色，表示**已经到达处理位置**

**要点**：以元素访问逆序入栈。因此一定都是先右后左。

时间复杂度： $O(n)$
空间复杂度： $O(n)$

### 中序

```python
class Solution:
    def inorderTraversal(self, root: TreeNode | None) -> list[int]:
        ans = []
        stack = []
        if root:
            stack.append((root, 0))

        while stack:
            node, color = stack.pop()

            if color == 0:
                # 第一次遇到节点：
                # 中序遍历要求先访问左子树
                if node.right:
                    stack.append((node.right, 0))

                # 标记为灰色，之后再次遇到时处理自己
                stack.append((node, 1))

                if node.left:
                    stack.append((node.left, 0))

            else:
                # 第二次遇到节点，访问自己
                    ans.append(node.val)

        return ans
```
