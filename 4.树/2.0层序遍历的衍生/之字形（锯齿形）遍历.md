## 之字形（锯齿形）遍历

题号： BM27，[LC103](https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/)
描述： 给定一个二叉树，返回该二叉树的之字形层序遍历，（第一层从左向右，下一层从右向左，一直这样交替）
思路： 在层序遍历基础上，按层反转。

### 队列

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def zigzagLevelOrder(self, root: TreeNode | None) -> list[list[int]]:
        ans = []
        if not root:
            return ans

        cur = [root]
        level = 1
        while cur:
            row = []
            nx = []
            for node in cur:
                row.append(node.val)
                if node.left:
                    nx.append(node.left)
                if node.right:
                    nx.append(node.right)
            # 偶数层反转
            if level % 2 == 0:
                row.reverse()
            ans.append(row)
            cur = nx
            level += 1

        return ans
```

### 递归

类似的，根据奇偶判断

时间复杂度： $O(n^2)$，列表头插`row.insert(0, node.val)`需要$O(n)$。
空间复杂度： $O(n)$

```python
class Solution:
    def zigzagLevelOrder(self, root: TreeNode | None) -> list[list[int]]:
        res = []

        def dfs(node, level):
            if not node:
                return
            # 第一次访问这一层时，创建一个新的列表
            if len(res) == level:
                res.append([])
            if level % 2 == 0:
                res[level].append(node.val)
            else:
                res[level].insert(0, node.val)

            # 层数+1, 递归处理左右子树
            level += 1
            dfs(node.left, level)
            dfs(node.right, level)

        dfs(root, 0)
        return res
```

        // 递归时层数+1
        traverse(root.Left, level+1)
        traverse(root.Right, level+1)
    }
}
