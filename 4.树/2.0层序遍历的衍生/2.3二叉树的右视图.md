## 二叉树的右视图

题号： BM41，[LC199](https://leetcode.cn/problems/binary-tree-right-side-view)

描述： 给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

思路：
- 最直观：层序遍历后取每层最后一个元素
- 最简单：**DFS右子树优先**

时间复杂度： $O(n)$
空间复杂度： $O(n)$

### DFS

```python
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        res = []

        def dfs(root, level):
            if root == None:
                return
            # 新的一层
            if len(res) == level:
                res.append(root.val)
                
            # 右子树优先
            dfs(root.right, level + 1)
            dfs(root.left, level + 1)

        dfs(root, 0)
        return res
```

类似的还有[LC153](https://leetcode.cn/problems/find-bottom-left-tree-value)找左下角的值，层序遍历右优先，最后出队的就是答案。

### BFS

BFS取最后一个元素

时间复杂度： $O(n)$
空间复杂度： $O(qsize)$，不超过`n`。

```python
import queue
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        if not root:
            return res
        q = queue.Queue()
        q.put(root)
        while not q.empty():
            size = q.qsize()
            while size > 0:
                size -= 1
                node = q.get()
                ## 最后一个元素
                if size == 0:
                    res.append(node.val)
                if node.left:
                    q.put(node.left)
                if node.right:
                    q.put(node.right)

        return res

```
