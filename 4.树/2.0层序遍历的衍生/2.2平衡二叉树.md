## 平衡二叉树

题号： BM36，[LC110](https://leetcode.cn/problems/balanced-binary-tree)
描述： 左右子树高度差不超过1

### 自底向上（dfs）

自底向上递归的做法类似于后序遍历，对于当前遍历到的节点，先递归地判断其左右子树是否平衡，再判断以当前节点为根的子树是否平衡。

时间复杂度：$O(n)$
空间复杂度：$O(h)$，树高，不超过`n`。

```python
class Solution:
    def isBalanced(self, root: TreeNode | None) -> bool:

        def getHeight(root):
            if root is None:
                return 0

            lheight = getHeight(root.left)
            if lheight == -1:
                return -1

            rheight = getHeight(root.right)
            if rheight == -1 or abs(lheight - rheight) > 1:
                return -1

            return 1 + max(lheight, rheight)
		# 用-1代表不平衡
        return getHeight(root) != -1
```
