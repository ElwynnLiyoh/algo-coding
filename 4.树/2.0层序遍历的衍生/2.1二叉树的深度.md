## 二叉树的最大深度

题号： BM28，[LC104](https://leetcode.cn/problems/maximum-depth-of-binary-tree)

### 递归

时间复杂度： $O(n)$，需要经过每个结点
空间复杂度： $O(n)$，最坏情况下，二叉树化为链表，递归栈深度最大为n

```python
class Solution:
    # 写法一
    def maxDepth(self, root: TreeNode) -> int:
        if not root:
            return 0
        ldepth = self.maxDepth(root.left)
        rdepth = self.maxDepth(root.right)
        # 左右最大+1
        return 1 + max(ldepth, rdepth)
    
    # 写法二
    def maxDepth(self, root: TreeNode) -> int:
        mdepth = 0

        def depth(root, cnt):
            if not root:
                return
            cnt += 1
            nonlocal mdepth
            mdepth = max(mdepth, cnt)
            depth(root.left, cnt)
            depth(root.right, cnt)

        depth(root, 0)
        return mdepth
```


### 层序遍历

时间复杂度： $O(n)$，需要经过每个结点
空间复杂度： $O(qsize)$

仅计算深度，不需要每层结果，因此更简单

```python
import queue
class Solution:
    def maxDepth(self, root: TreeNode) -> int:
        if not root:
            return 0

        q = queue.Queue()
        q.put(root)
        depth = 0
        while not q.empty():
            for _ in range(q.qsize()):
                node = q.get()
                if node.left:
                    q.put(node.left)
                if node.right:
                    q.put(node.right)
            depth += 1

        return depth
```
