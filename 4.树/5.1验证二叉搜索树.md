## 验证二叉𫍲索树

题号： BM34，[LC98](https://leetcode.cn/problems/validate-binary-search-tree/)
描述： 
**有效** 二叉搜索树定义如下：
- 节点的左子树只包含 **严格小于** 当前节点的数。
- 节点的右子树只包含 **严格大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

### 递归

要点：需要传入左右边界。

时间复杂度： $O(n)$
空间复杂度： $O(n)$

**前序遍历**（推荐）

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        return self.check(root)

    # 默认参数初始化正负无穷
    def check(self, root, lower=-inf, upper=inf):
        if root is None:
            return True
        x = root.val
        return (
            lower < x < upper
            and self.check(root.left, lower, x)
            and self.check(root.right, x, upper)
        )
```

**中序遍历**

```python
class Solution:
    pre = -inf

    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True
        # 左
        if self.isValidBST(root.left) == False:
            return False
        # 中
        if self.pre >= root.val:
            return False

        self.pre = root.val  # 保存中间的值

        # 右
        return self.isValidBST(root.right)
```


**后序遍历**（太复杂，不推荐）

### 栈

使用栈实现**中序遍历**，然后检查遍历的结果。

时间复杂度： $O(n)$
空间复杂度： $O(n)$，栈最多存储`n`个节点。

```python
def isValidBST(self, root: TreeNode) -> bool:
    # res保存结果，stack记录中序遍历的数组
    res, stack = [], []
    head = root
    while head or stack:
        # 到最左
        while head:
            stack.append(head)
            head = head.left
        # 记录节点
        node = stack.pop()
        res.append(node.val)
        # 往右走
        head = node.right

    # 检查中序结果
    for i in range(1, len(res)):
        if res[i - 1] > res[i]:
            return False
    return True
```
