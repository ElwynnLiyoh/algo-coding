## 二叉搜索树的最近公共祖先

题号： BM37
描述： 给定一个二叉搜索树, 找到该树中两个指定节点的最近公共祖先。
思路： 

- step 1：首先检查空节点，空树没有公共祖先。
- step 2：对于某个节点，比较与p、q的大小，若p、q在该节点两边说明这就是最近公共祖先。
- step 3：如果p、q都在该节点的左边，则递归进入左子树。
- step 4：如果p、q都在该节点的右边，则递归进入右子树。



### 递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def lowestCommonAncestor(self, root: TreeNode, p: int, q: int) -> int:
    lower = min(p, q)
    upper = max(p, q)

    def lca(head, lower, upper) -> int:
        # 空树没有公共祖先
        if not head:
            return -1
        # 在两者之间，就是最近公共祖先
        if lower <= head.val <= upper:
            return head.val
        # 比小还小，往右走
        elif head.val < lower:
            return lca(head.right, lower, upper)
        else:
            return lca(head.left, lower, upper)

    return lca(root, lower, upper)
```



### 非递归（最优）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
def lowestCommonAncestor(self, root: TreeNode, p: int, q: int) -> int:
    lower = min(p, q)
    upper = max(p, q)
    head=root
    while True:
        if head.val<lower:
            head=head.right
        elif head.val>upper:
            head=head.left
        else:
            break

    return head.val
```



## 二叉树的最近公共祖先

题号： BM38, LC236
描述： 给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
# LC版
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # Base case：如果 root 是空，或就是 p 或 q，直接返回
        if not root or root == p or root == q:
            return root
            
        # 在左子树中找 p 或 q
        left = self.lowestCommonAncestor(root.left, p, q)
        # 在右子树中找 p 或 q
        right = self.lowestCommonAncestor(root.right, p, q)

        # 情况1：左右都找到 → 当前 root 就是最近公共祖先
        if left and right:
            return root
        # 情况2：只找到一个 → 把找到的那个返回
        elif left:
            return left
        else:
            return right

# NC版
class Solution:
    def lowestCommonAncestor(self, root: TreeNode, o1: int, o2: int) -> int:
        if not root:
            return -1
        if root.val == o1 or root.val == o2:
            return root.val
        left = self.lowestCommonAncestor(root.left, o1, o2)
        right = self.lowestCommonAncestor(root.right, o1, o2)
        if left > 0 and right > 0:
            return root.val
        if left == -1:
            return right
        else:
            return left
```
