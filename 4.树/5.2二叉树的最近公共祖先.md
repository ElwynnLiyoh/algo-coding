## 二叉搜索树的最近公共祖先

题号：BM37，[LC235](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/)
描述：给定一个**二叉搜索树**, 找到该树中两个指定节点的最近公共祖先。
思路：

- step 1：首先检查空节点，空树没有公共祖先。
- step 2：对于某个节点，比较与p、q的大小，若p、q在该节点两边说明这就是最近公共祖先。
- step 3：如果p、q都在该节点的左边，则递归进入左子树。
- step 4：如果p、q都在该节点的右边，则递归进入右子树。

### 递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def lowestCommonAncestor(self, root, p, q) -> TreeNode:
    x = root.val
    if x < p.val and x<q.val:
        return self.lowestCommonAncestor(root.right,p,q)
    elif x > p.val and x> q.val:

def lowestCommonAncestor(self, root, p, q) -> TreeNode:
    # 提前区分小的和大的
    lower = min(p.val, q.val)
    upper = max(p.val, q.val)

    def lca(head, lower, upper):
        # 因为p,q都存在，一直往p/q方向走，所以一定不会遇到空，因此不需要判空
        x = head.val
        # 比小还小，往右走
        if x < lower:
            return lca(head.right, lower, upper)
        # 比大还大，往左走
        elif x > upper:
            return lca(head.left, lower, upper)
        # 在两者之间，就是最近公共祖先
        else:
            return head

    return lca(root, lower, upper)
```


### 非递归（最优）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
def lowestCommonAncestor(self, root, p, q) -> TreeNode:
    lower = min(p.val, q.val)
    upper = max(p.val, q.val)
    cur = root
    while cur:
        if cur.val < lower:
            cur = cur.right
        elif cur.val > upper:
            cur = cur.left
        else:
            break
    return cur
```



## 二叉树的最近公共祖先

题号： BM38，[LC236](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)
描述： 给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
# LC版
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # Base case：如果 root 是空，或就是 p 或 q，直接返回
        if not root or root == p or root == q:
            return root
            
        # 在左子树中找 p 或 q
        left = self.lowestCommonAncestor(root.left, p, q)
        # 在右子树中找 p 或 q
        right = self.lowestCommonAncestor(root.right, p, q)

        # 情况1：左右都找到 → 当前 root 就是最近公共祖先
        if left and right:
            return root
        # 情况2：只找到一个 → 把找到的那个返回
        elif left:
            return left
        else:
            return right

# NC版
class Solution:
    def lowestCommonAncestor(self, root: TreeNode, o1: int, o2: int) -> int:
        if not root:
            return -1
        if root.val == o1 or root.val == o2:
            return root.val
        left = self.lowestCommonAncestor(root.left, o1, o2)
        right = self.lowestCommonAncestor(root.right, o1, o2)
        if left > 0 and right > 0:
            return root.val
        if left == -1:
            return right
        else:
            return left
```
