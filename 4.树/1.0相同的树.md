## 相同的树

题号： [LC100](https://leetcode.cn/problems/same-tree/description/)
描述： 给你两棵二叉树的根节点 `p` 和 `q` ，编写一个函数来检验这两棵树是否相同。
思路： 
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def isSameTree(self, p: TreeNode | None, q: TreeNode | None) -> bool:
        if not p or not q:
	        # 两个都为None才是True
            return p is q
            
        if p.val != q.val:
            return False

        lsame = self.isSameTree(p.left, q.left)
        rsame = self.isSameTree(p.right, q.right)
        return lsame and rsame
```
