## 二叉树的镜像

题号： BM33
描述： 操作给定的二叉树，将其变换为源二叉树的镜像。

### 递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
class Solution:
    def Mirror(self , pRoot ):
        if not pRoot:
            return pRoot
        # 左右子树交换
        pRoot.left, pRoot.right = pRoot.right, pRoot.left
        # 递归左右子树
        self.Mirror(pRoot.left)
        self.Mirror(pRoot.right)
        return pRoot
```


### 栈

二叉树中能够用递归的，我们大多也可以用栈来实现。栈的访问是一种自顶向下的访问，因此我们需要在左右子节点入栈后直接交换，然后再访问后续栈中内容。

**具体做法：**

- step 1：优先检查空树的情况。
- step 2：使用栈辅助遍历二叉树，根节点先进栈。
- step 3：遍历过程中每次弹出栈中一个元素，然后该节点左右节点分别入栈。
- step 4：同时我们交换入栈两个子节点的值，因为子节点已经入栈了再交换，就不怕后续没有交换。

```python
class Solution:
    def Mirror(self , pRoot: TreeNode) -> TreeNode:
        # 空树
        if not pRoot:  
            return None
        # 辅助栈
        s = [] 
        # 根节点先进栈
        s.append(pRoot) 
        while s:
            node = s[-1]
            s.pop()
            # 左右节点入栈
            if node.left:
                s.append(node.left) 
            if node.right:
                s.append(node.right)
            # 交换左右
            temp = node.left  
            node.left = node.right
            node.right = temp
        return pRoot

```
