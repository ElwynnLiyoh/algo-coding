## 出现次数超过一半的数字

题号： BM51

### 哈希法
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def MoreThanHalfNum_Solution(self, numbers: List[int]) -> int:
    hashMap = {}
    half = len(numbers) >> 1
    for idx, val in enumerate(numbers):
        hashMap[val] = hashMap.get(val, 0) + 1
        # 因为数组下标从0开始，故idx >= half 而不是 idx > half
        if idx >= half and hashMap[val] > half:
            return val

    return 0
```



### Boyer-Moore 摩尔投票法 （最优解）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

与候选数字相同则+1票，其余都是反对票

由于答案出现次数 > n/2，所以即使把它和所有其他数字进行抵消，仍然会有剩余。

```python
def MoreThanHalfNum_Solution(self, numbers: List[int]) -> int:
    #candidate：当前候选数字
    #count：候选数字的票数
    candidate = numbers[0]
    count = 0

    for num in numbers:
        if count == 0:
            candidate = num

        if num == candidate:
            count += 1
        else:
            count -= 1

    return candidate
```
