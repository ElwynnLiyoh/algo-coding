## 只出现一次的数字

题号： NC231, LC136
时间复杂度： $O(n)$
空间复杂度： $O(1)$

**最优解**需要用到**异或**

- 交换律： a^b = b^a
- 结合率： (a^b)^c = a^(b^c)
- 0^a = a, a^a = 0

例如： [4, 1, 2, 1, 2]

根据交换律，故看成 [4, 1, 1, 2, 2]

根据结合率，有 4 ^ (1^1) ^ (2^2) = 4 ^ 0 ^ 0 = 4

```python
def singleNumber(self, nums: List[int]) -> int:
    res = 0
    for num in nums:
        res ^= num
    return res
```


## 只出现一次的数字(2)

题号： NC227, LC137

描述： 给定一个整数数组，数组中有一个数出现了一次，其他数出现了三次，请找出只出现了一次的数。

时间复杂度： $O(32n)$
空间复杂度： $O(1)$

### 位运算

这是最优思路。看成2进制，数字出现了3次意味着2进制位1出现的次数全部加起来一定是3的倍数

其他思路：哈希、排序

```c++
int singleNumber(vector<int>& nums) {
    int ans = 0;
    for (int i = 0; i < 32; i++) {
        int cnt = 0;
        for (auto& num : nums) {
            cnt += num >> i & 1;
        }
        if (cnt % 3 > 0) {
            ans |= 1 << i;
        }
    }
    return ans;
}
```



### 状态机（效率最高的解法）

更加精妙绝伦！

时间复杂度： $O(n)$
空间复杂度： $O(1)$

`&^`是 Go 特有的 **AND NOT（位清除）** 运算。

`a &^ b` 相当于 `a & (^b)`, 也就是先把 `b` 按位取反，然后和 `a` 做 AND。

单bit真值表：

| `a`  | `b`  | `a &^ b` |
| ---- | ---- | -------- |
| 0    | 0    | 0        |
| 0    | 1    | 0        |
| 1    | 0    | 1        |
| 1    | 1    | 0        |

即：

b = 0 → 保留 a
b = 1 → 清除 a

可以把 `&^` 理解成：**a 中删除 b 所指定的 bit**

取反`^b`相当于是`(-1)^b` , -1的补码全为1

```go
func singleNumber(nums []int) int {
  	//ones：出现次数 % 3 == 1 的 bit
		//twos：出现次数 % 3 == 2 的 bit
    ones, twos := 0, 0
    for _, num := range nums {
        ones = (ones ^ num) &^ twos
        twos = (twos ^ num) &^ ones
    }

    return ones
}
```

状态机不显式统计次数，而是用 `ones/twos` 实时保存每个 bit 的 `count % 3`，当出现3次即清零。



## 只出现一次的两个数字

时间复杂度： $O(n)$
空间复杂度： $O(1)$

描述： 一个整型数组里除了两个数字只出现一次，其他的数字都出现了两次。

**思路**：

设这两个数字分别为a, b，全部异或一遍，得到`a^b` 。问题在于将a, b分开。

全部 XOR
    ↓
得到 a ^ b
    ↓
xor & -xor
    ↓
找到 a、b 不同的某一个 bit
    ↓
按照这个 bit 分组
    ↓
两组分别 XOR
    ↓
得到 a、b

```go
func singleNumbers(nums []int) []int {
    xor := 0

    // 1. 得到两个只出现一次的数字的 XOR
    for _, num := range nums {
        xor ^= num
    }

    // 2. 找到最低位的 1
    mask := xor & -xor

    a, b := 0, 0

    // 3. 根据 mask 分成两组。相同的数一定会被分到同一组，故两次异或后等于0
    for _, num := range nums {
        if num&mask == 0 {
            a ^= num
        } else {
            b ^= num
        }
    }

    // 4. 按非降序输出
  	// res := sort.Ints([]int{a, b})
    if a > b {
        a, b = b, a
    }
		
    return []int{a, b}
}
```

其中找到第一个不同的 `1` , `xor & -xor` 是一个位运算技巧，也可以用土方法

```go
	mask := 1
	for mask&xor == 0 {
		mask <<= 1
	}
```
