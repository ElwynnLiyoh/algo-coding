## 乘积小于K的子数组

题号： [LC713](https://leetcode.cn/problems/subarray-product-less-than-k/)
描述： 给定一个整数数组 `nums` 和一个整数 `k`。请你返回 **子数组** 内所有元素的 **乘积严格小于** `k` 的连续子数组的数目。

思路： 假如`[l, r]`的乘积小于`k`，那么`l+1, r]`...`[r, r]`都满足条件。则子数组的个数就是从`l`到`r`的元素个数。即`r-l+1`。
循环条件： 从 **不满足 -> 满足**

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
def numSubarrayProductLessThanK(self, nums: list[int], k: int) -> int:
    if k <= 1:
        return 0

    cnt = 0
    left = 0
    prod = 1

    for right in range(len(nums)):
        # 向右扩展
        prod *= nums[right]
        # 遇到不满足条件，立即开始收缩
        while prod >= k:
            prod /= nums[left]
            left += 1
        # 累计
        cnt += right - left + 1

    return cnt
```
