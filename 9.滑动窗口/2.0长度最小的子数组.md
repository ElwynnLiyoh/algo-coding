## 长度最小的子数组

题号： [LC209](https://leetcode.cn/problems/minimum-size-subarray-sum/description/)
描述： 给定一个含有 `n` 个正整数的数组和一个正整数 `target`。找出该数组中满足其总和大于等于 `target` 的长度最小的 **子数组** `[numsl, numsl+1, ..., numsr-1, numsr]` ，并返回其长度。如果不存在符合条件的子数组，返回 `0` 。

思路： 每次向右扩展，然后把左边收缩到能满足条件的最小窗口。即从 **满足 -> 不满足**。

时间复杂度： $O(n)$，`left`和`right`都至多移动`n`次。
空间复杂度： $O(1)$

```python
# 写法一
def minSubArrayLen(self, target: int, nums: list[int]) -> int:
    n = len(nums)
    ans = n + 1 # inf
    s = 0 # sum
    left = 0

    for right in range(n):
        # 纳入右边
        s += nums[right]
        # 再把左边收缩到最小
        while s - nums[left] >= target:
            s -= nums[left]
            left += 1

        if s >= target:
            ans = min(ans, right - left + 1)

    return ans if ans <= n else 0

# 写法二
def minSubArrayLen(self, target: int, nums: list[int]) -> int:
    n = len(nums)
    ans = n + 1 # inf
    s = 0 # sum
    left = 0

    for right in range(n):
        # 纳入右边
        s += nums[right]
        # 只要窗口还满足目标，就一直收缩左边
        while s >= target:
            ans = min(ans, right - left + 1)
            s -= nums[left]
            left += 1

    return ans if ans <= n else 0
```
