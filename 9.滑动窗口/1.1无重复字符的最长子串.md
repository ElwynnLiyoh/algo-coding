## 无重复字符的最长子串

题号： [LC3](https://leetcode.cn/problems/longest-substring-without-repeating-characters)
描述： 给定一个字符串 `s` ，找出其中不含有重复字符的 **最长子串** 的长度。

### 哈希+滑动窗口

时间复杂度： $O(n)$
空间复杂度： $O(len(set(s)))$, 仅由字符集大小决定。

```python
# 写法一：Counter
# Counter: 专门用于统计元素出现次数的字典
# Counter 访问不存在的 key 时返回 0，而不是 KeyError。
from collections import Counter
def lengthOfLongestSubstring(self, s: str) -> int:
    # hash={c: cnt}
    cnt = Counter()
    left = 0
    maxlen = 0

    for right, c in enumerate(s):
        # 向右扩展
        cnt[c] += 1
        # 不满足条件，则收缩
        while cnt[c] > 1:
            cnt[s[left]] -= 1
            left += 1
        # 计算长度
        maxlen = max(maxlen, right - left + 1)

    return maxlen

# 写法二：集合
def lengthOfLongestSubstring(self, s: str) -> int:
    memo = set()
    left = 0
    maxlen = 0

    for right, c in enumerate(s):
        while c in memo:
            memo.remove(s[left])
            left += 1
            
        memo.add(c)
            
        # 计算长度
        maxlen = max(maxlen, right - left + 1)

    return maxlen
```


### 记忆哈希

利用字典记录元素**上一次出现的位置**，下次遇到重复元素时可以直接跳过中间移动过程。

时间复杂度： $O(n)$
空间复杂度： $O(len(set(s)))$, 仅由字符集大小决定。

```python
def lengthOfLongestSubstring(self, s: str) -> int:
    # key=char, value=index
    memo = {}
    maxlen = 0
    left = 0

    for right, c in enumerate(s):
        # 上次出现的字符还在窗口内才需要移动
        if c in memo and memo[c] >= left:
            left = memo[c] + 1
        # 更新字符出现位置
        memo[c] = right

        maxlen = max(maxlen, right - left + 1)

    return maxlen
```
