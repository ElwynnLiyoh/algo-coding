## 最长无重复子数组

题号： BM92
描述： 给定一个长度为n的数组arr，返回arr的最长无重复元素子数组的长度，无重复指的是所有数字都不相同。子数组是连续的，比如[1,3,5,7,9]的子数组有[1,3]，[3,5,7]等等，但是[1,3,7]不是子数组

思路： 哈希+滑动窗口
时间复杂度： $O(n)$
空间复杂度： $O(10)$，只有`0~9`数字。

```python
def maxLength(arr):
    window = set()
    left = 0
    max_len = 0

    for right in range(len(arr)):
        # 如果 arr[right] 已经在窗口中，
        # 不断移动 left，直到重复元素被移除
        while arr[right] in window:
            window.remove(arr[left])
            left += 1

        window.add(arr[right])
        max_len = max(max_len, right - left + 1)

    return max_len
```



**最优**：可以利用字典记录元素**上一次出现的位置**，这样遇到重复元素时可以直接跳过中间过程

```python
def maxLength(arr):
    last = {}
    left = 0
    max_len = 0

    for right, num in enumerate(arr):
        if num in last and last[num] >= left:
	        # 找到上一次出现的位置，再往前一步跳过
            left = last[num] + 1

        last[num] = right
        max_len = max(max_len, right - left + 1)

    return max_len
```
