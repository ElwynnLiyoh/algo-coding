## 二叉树的中序线索化(双向链表)

题号： BM30
描述： 
思路： 
时间复杂度： $O()$
空间复杂度： $O()$

```python
class Solution:
    pre = None  # 记录前驱节点
    root = None  # 记录要返回的根节点

    def Convert(self, pRootOfTree):
        if pRootOfTree == None:
            return self.root

        # 递归到最左边
        self.Convert(pRootOfTree.left)

        # 开始构建中序线索二叉树
        if self.root == None:
            self.root = pRootOfTree  # 根节点只记录一次，后续都不会变
        if self.pre != None:
            pRootOfTree.left = self.pre  # 赋值当前节的前驱
            self.pre.right = pRootOfTree  # 赋值前驱节点的后继
        self.pre = pRootOfTree  # 更新前驱的记录

        self.Convert(pRootOfTree.right)
        return self.root

```
