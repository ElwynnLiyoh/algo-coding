## 合并二叉树

题号： BM32
描述： 已知两颗二叉树，将它们合并成一颗二叉树。合并规则是：都存在的结点，就将结点值加起来，否则空的位置就由另一个树的结点来代替。
思路： 直接在t1上修改
时间复杂度： $O(n)$
空间复杂度： $O(1)$


```python
def mergeTrees(t1, t2):
    # t1 不存在，直接使用 t2
    if not t1:
        return t2

    # t2 不存在，保持 t1
    if not t2:
        return t1

    # 两个节点都存在
    t1.val += t2.val

    # 合并左右子树
    t1.left = mergeTrees(t1.left, t2.left)
    t1.right = mergeTrees(t1.right, t2.right)

    return t1
```
