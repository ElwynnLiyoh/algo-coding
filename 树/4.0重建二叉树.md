## 前序+中序

题号： BM40，LC105
描述： 给定节点数为 n 的二叉树的前序遍历和中序遍历结果，请重建出该二叉树并返回它的头结点。
思路： 找根节点

### 递归

时间复杂度： $O(n)$，遍历每一个节点
空间复杂度： $O(n)$，反回树占用的空间

```python
class Solution:
    # 返回构造的TreeNode根节点
    def reConstructBinaryTree(self, pre, in):
        if not pre:
            return None
        # 根节点
        root = TreeNode(pre[0])
        # 根节点在中序遍历中的位置索引
        i = in.index(pre[0])
        # 递归 构造树左右子树
        root.left = self.reConstructBinaryTree(pre[1:i+1], in[:i])
        root.right = self.reConstructBinaryTree(pre[i+1:], in[i+1:])
        return root
```



### 栈

模拟递归时的**函数调用栈**。



核心思想

先序遍历不断提供：

> **下一个应该创建的节点**

中序遍历告诉我们：

> **什么时候一个节点的左子树已经构造完成，可以开始构造右子树。**

我们维护：`stack`以及：`inorderIndex`

其中`stack`存储从根节点到当前正在构造节点的路径上，那些还没有完全确定右子树的节点。 `inorderIndex` 指向当前中序遍历正在处理的节点。

```python

class Solution:
    def reConstructBinaryTree(self, preOrder: List[int], inOrder: List[int]) -> TreeNode:
        if not preOrder:
            return None

        root = TreeNode(preOrder[0])

        stack = [root]

        # 指向当前正在处理的中序节点
        inOrder_index = 0

        for val in preOrder[1:]:
            node = TreeNode(val)

            # 栈顶节点还没有处理完左子树
            if stack[-1].val != inOrder[inOrder_index]:
                stack[-1].left = node
                stack.append(node)

            else:
                # 找到最后一个已经完成左子树的节点
                parent = None

                while stack and stack[-1].val == inOrder[inOrder_index]:
                    parent = stack.pop()
                    inOrder_index += 1

                # 新节点成为最后弹出节点的右孩子
                parent.right = node
                stack.append(node)

        return root

```
