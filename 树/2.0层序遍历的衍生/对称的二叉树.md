## 对称的二叉树

题号： BM31，LC101
描述： 

### 递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$，最坏情况二叉树退化为链表，递归栈深度为nn

```go
func isSymmetric(pRoot *TreeNode) bool {
    // 如果两边都传入root（sym(pRoot, pRoot)）, 会造成两次遍历
    if pRoot == nil {
      	return true
    }
    return sym(pRoot.Left, pRoot.Right)
}

func sym(lroot *TreeNode, rroot *TreeNode) bool {
    if lroot == nil && rroot == nil {
      	return true
    }
    // 仅有一个为空或值不同，必不对称
    if lroot == nil || rroot == nil || lroot.Val != rroot.Val {
      	return false
    }
    // 对称的位置递归
    return sym(lroot.Left, rroot.Right) && sym(lroot.Right, rroot.Left)
}
```



### 迭代（BFS）

思路：维护两个队列，相反的入队顺序

时间复杂度： $O(n)$
空间复杂度： $O(n)$，每个节点最多进队一次，出队一次，队列中最多不会超过 *n* 个点，故渐进空间复杂度为 *O*(*n*)。

```python
import queue
class Solution:
    def isSymmetric(self, pRoot: TreeNode) -> bool:
        if pRoot == None:
            return True
        q1, q2 = queue.Queue(), queue.Queue()
        q1.put(pRoot.left)
        q2.put(pRoot.right)
        while not q1.empty() and not q2.empty():
            node1 = q1.get()
            node2 = q2.get()
            if node1 == None and node2 == None:
                continue
            if node1 == None or node2 == None or node1.val != node2.val:
                return False
            # 先左后右
            q1.put(node1.left)
            q1.put(node1.right)
            # 先右后左
            q2.put(node2.right)
            q2.put(node2.left)
        return True
```



也可以只用一个队列，注意此时节点和左右入队顺序都要交替

```go
func isSymmetric(root *TreeNode) bool {
    u, v := root, root
    q := []*TreeNode{}
    q = append(q, u)
    q = append(q, v)
    for len(q) > 0 {
        u, v = q[0], q[1]
        q = q[2:]
        if u == nil && v == nil {
            continue
        }
        if u == nil || v == nil {
            return false
        }
        if u.Val != v.Val {
            return false
        }
        q = append(q, u.Left)
        q = append(q, v.Right)

        q = append(q, u.Right)
        q = append(q, v.Left)
    }
    return true
}
```
