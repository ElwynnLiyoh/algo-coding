## 之字形（锯齿形）遍历

题号： BM27, LC103
描述： 给定一个二叉树，返回该二叉树的之字形层序遍历，（第一层从左向右，下一层从右向左，一直这样交替）
思路： 在层序遍历基础上，按层反转或在添加时判断



### 队列

时间复杂度： $O(n^2)$，列表头插row.insert(0, node.val)需要O(n)
空间复杂度： $O(n)$

```python
import queue
class Solution:
    def Print(self, root: TreeNode) -> List[List[int]]:
        res = []
        if not root:
            return res

        q = queue.Queue()
        q.put(root)
        level = 1
        while not q.empty():
            row = []  # 记录一层
            for _ in range(q.qsize()):
                node = q.get()
                if level % 2 == 1:
                    row.append(node.val)
                else:
                    row.insert(0, node.val)
                if node.left:
                    q.put(node.left)
                if node.right:
                    q.put(node.right)

            level += 1
            res.append(row)

        return res
```

为避免头插的开销，最简单的办法是层序遍历后反转。

此时时间降为O(n)

```python
for i in range(len(res)):
            if i%2==1:
                res[i].reverse()
```

时间复杂度： $O(n)$
空间复杂度： $O(n)$

### 递归

类似的，根据奇偶判断

```go
var res = [][]int{}
func Print( pRoot *TreeNode ) [][]int {
    traverse(pRoot, 1)
    return res
}
 
func traverse(root *TreeNode, level int) {
    if root != nil {
        // 新的一层
        if len(res) < level {
            res = append(res, []int{})
        }
        // 元素添加入这一层
        if level%2==1{
            res[level-1] = append(res[level-1], root.Val)
        } else{
            res[level-1]=append([]int{root.Val},res[level-1]...)
        }
        // 递归时层数+1
        traverse(root.Left, level+1)
        traverse(root.Right, level+1)
    }
}
```
