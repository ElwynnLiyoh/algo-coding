## 判断是不是完全二叉树

题号： BM35
描述： 完全二叉树的定义：若二叉树的深度为 h，除第 h 层外，其它各层的结点数都达到最大个数，第 h 层所有的叶子结点都连续集中在最左边，这就是完全二叉树。（第 h 层可能包含 [1~2h] 个节点）

### BFS
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
import queue
class Solution:
    def isCompleteTree(self, root: TreeNode) -> bool:
        if not root:
            return True

        q = queue.Queue()
        q.put(root)
        flag = False  # 记录第一个出现的空节点
        while not q.empty():
            # for _ in range(q.qsize()):  # 不需要保存每一层的结果，所以这个循环可以不要
                node = q.get()
                if node == None:
                    flag = True
                    continue
                if flag:
                    return False
				# 因为要记录第一个空节点，所以不用判断左右节点是否空
                q.put(node.left)
                q.put(node.right)

        return True
```


### 利用数学关系

完全二叉树中编号最大的那个结点，编号刚好等于结点数。

任意的遍历方式都可以

```python
class Solution:
    def isCompleteTree(self, root: TreeNode) -> bool:
        if not root:
            return True

        nodes = [(root, 1)]
        idx = 0
        while idx < len(nodes):
            node, i = nodes[idx]
            idx += 1
            if node:
                nodes.append((node.left, 2 * i))
                nodes.append((node.right, 2 * i + 1))

        return nodes[-1][-1] == idx
```



dfs

```python
class Solution:
    count = 0
    maxIndex = 0

    def isCompleteTree(self, root: TreeNode) -> bool:
        def dfs(root, idx):
            if not root:
                return
            self.count += 1
            self.maxIndex = max(self.maxIndex, idx)
            dfs(root.left, idx * 2)
            dfs(root.right, idx * 2 + 1)

        dfs(root, 1)
        return self.count == self.maxIndex
```
