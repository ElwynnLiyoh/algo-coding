## 二叉树的最大深度

题号： BM28

### 递归

时间复杂度： $O(n)$，需要经过每个结点
空间复杂度： $O(n)$，最坏情况下，二叉树化为链表，递归栈深度最大为n

```python
class Solution:
    def maxDepth(self, root: TreeNode) -> int:
        if not root:
            return 0
        # 左右最大+1
        return max(self.maxDepth(root.left), self.maxDepth(root.right)) + 1
```


### 层序遍历

时间复杂度： $O(n)$，需要经过每个结点
空间复杂度： $O(qsize)$

仅计算深度，不需要每层结果，因此更简单

```python
import queue
class Solution:
    def maxDepth(self, root: TreeNode) -> int:
        if not root:
            return 0

        q = queue.Queue()
        q.put(root)
        depth = 0
        while not q.empty():
            for _ in range(q.qsize()):
                node = q.get()
                if node.left:
                    q.put(node.left)
                if node.right:
                    q.put(node.right)
            depth += 1

        return depth
```


## 平衡二叉树

题号： BM36
描述： 左右子树高度差不超过1

### 自顶向下

时间复杂度： $O(n^2)$
空间复杂度： $O(n)$

会造成重复计算
```python
class Solution:
    def IsBalanced_Solution(self, pRoot):
        if not pRoot:
            return True

        diff = self.height(pRoot.left) - self.height(pRoot.right)

        return (
            abs(diff) <= 1
            and self.IsBalanced_Solution(pRoot.left)
            and self.IsBalanced_Solution(pRoot.right)
        )

    def height(self, root):
        if not root:
            return 0

        return max(
            self.height(root.left),
            self.height(root.right),
        ) + 1
```

### 自底向上（dfs）

时间复杂度：$O(n)$
空间复杂度：$O(h)$，树高

```python
class Solution:
    def IsBalanced_Solution(self, pRoot):

        def heigh(root) -> int:
            if not root:
                return 0

            left_height = height(root.left)
            if left_height == -1:
                return -1

            right_height = height(root.right)
            if right_height == -1:
                return -1

            if abs(left_height - right_height) > 1:
                return -1

            return max(left_height, right_height) + 1

        return height(pRoot) != -1
```
