## 反转字符串

题号： BM91
描述： 
思路： 
时间复杂度： $O(n)$
空间复杂度： $O(n)$

python：

最优解：原地交换（双指针），空间 O(1)

```python
def reverse(s: str) -> str:
    chars = list(s)

    left, right = 0, len(chars) - 1

    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1

    return ''.join(chars)
```

最简单：

```python
def solve(self, s: str) -> str:
    rev = ""
    for i in s:
        rev = i + rev
    return rev
```

```python
def solve(self, str: str) -> str:
    rev = ''
    for i in range(len(str) - 1, -1, -1):
        rev += str[i]
    return rev
```

```go
func solve( str string ) string {
    var tmp []byte
    for i:=len(str)-1;i>=0;i--{
        tmp=append(tmp, str[i])
    }
    return string(tmp)
}
```


```go
func solve( str string ) string {

    }
    return sb.String()
```

预分配内存：

```go
func solve(s string) string {
    res := make([]byte, len(s))

    for i := 0; i < len(s); i++ {
        res[len(s)-1-i] = s[i]
    }

    return string(res)
}
```

支持unicode:

```go
func reverse(s string) string {
    runes := []rune(s)
    res := make([]rune, len(runes))

    for i := 0; i < len(runes); i++ {
        res[len(runes)-1-i] = runes[i]
    }

    return string(res)
}
```



原地交换（**最优**）：

空间复杂度： $O(1)$

```go
func reverse(s string) string {
    b := []byte(s)

    for i, j := 0, len(b)-1; i < j; i, j = i+1, j-1 {
        b[i], b[j] = b[j], b[i]
    }

    return string(b)
}
```
