## 最长公共前缀

题号： BM84 ,LC14
描述： 给你一个大小为 n 的字符串数组 strs ，其中包含n个字符串 , 编写一个函数来查找字符串数组中的最长公共前缀，返回这个公共前缀。
思路： 
时间复杂度： $O(n*len)$
空间复杂度： $O(1)$

### 纵向比较

```go
func longestCommonPrefix(strs []string) string {
	if len(strs) == 0 {
		return ""
	}
	for i := 0; i < len(strs[0]); i++ {
		c := strs[0][i]
		for j := 1; j < len(strs); j++ {
            // 当i==len(strs[j])时，后面strs[j][i]会越界
			if i == len(strs[j]) || c != strs[j][i] {
				return strs[0][:i]
			}
		}
	}
	return strs[0]
}

```



### 横向比较

```go
func longestCommonPrefix(strs []string) string {
	if len(strs) == 0 {
		return ""
	}

	prefix := strs[0]

	for i := 1; i < len(strs); i++ {
		prefix = commonPrefix(prefix, strs[i])

		if prefix == "" {
			return ""
		}
	}

	return prefix
}

func commonPrefix(s1, s2 string) string {
	n := min(len(s1), len(s2))

	i := 0
	for i < n && s1[i] == s2[i] {
		i++
	}

	return s1[:i]
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}
```



###　分治

递归对半分，求左前缀和右前缀，需要递归调用栈，空间$O(\log n)$

```go
func longestCommonPrefix(strs []string) string {
	if len(strs) == 0 {
		return ""
	}

	if len(strs) == 1 {
		return strs[0]
	}

	mid := len(strs) / 2

	left := longestCommonPrefix(strs[:mid])
	right := longestCommonPrefix(strs[mid:])

	n := min(len(left), len(right))

	i := 0
	for i < n && left[i] == right[i] {
		i++
	}

	return left[:i]
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}
```
