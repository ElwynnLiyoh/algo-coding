## 字符串变形

题号： BM83
描述： 把这个字符串中由空格隔开的单词反序，同时反转每个字符的大小写。
思路： 
时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def trans(self, s: str, n: int) -> str:
    words = s.split(" ")[::-1]
    words = " ".join(words)
    return words.swapcase()
```

土法编程：
`32 = 0010 0000`,
```
'A' = 65 = 0100 0001 
'a' = 97 = 0110 0001
             ↑
             32
```
所以 `c ^= 32`即可在大小写之间转换。

```go
func trans(s string, n int) string {
	words := strings.Split(s, " ")

	for i := range words {
		words[i] = swapCase(words[i])
	}

	for left, right := 0, len(words)-1; left < right; left, right = left+1, right-1 {
		words[left], words[right] = words[right], words[left]
	}

	return strings.Join(words, " ")
}

func swapCase(s string) string {
	b := []byte(s)
    // 古法
	// for i := range b {
	// 	if b[i] >= 'a' && b[i] <= 'z' {
	// 		b[i] -= 32
	// 	} else if b[i] >= 'A' && b[i] <= 'Z' {
	// 		b[i] += 32
	// 	}
	// }

    for i := range b {
		if (b[i] >= 'a' && b[i] <= 'z') ||
			(b[i] >= 'A' && b[i] <= 'Z') {
			b[i] ^= 32
		}
	}

	return string(b)
}

```



最优：只需要扫一遍

```go
func trans(s string, n int) string {
    var result strings.Builder
    result.Grow(n)	// 预留内存

    bytes := []byte(s)

    // wordEnd 表示当前单词的结束位置
    wordEnd := n

    for i := n - 1; i >= 0; i-- {
        // 遇到空格，说明找到了一个单词
        if bytes[i] == ' ' {
            result.Write(bytes[i+1 : wordEnd])
            result.WriteByte(' ')

            // 下一个单词的结束位置
            wordEnd = i
            continue
        } else {
            // 英文字母大小写转换
            bytes[i] ^= 32
        }
    }

    // 写入第一个单词到最后面（因为第一个单词的前面没有空格了）
    result.Write(bytes[:wordEnd])

    return result.String()
}
```
