## I 所有元素都只出现一次

题号： BM15, [LC83](https://leetcode.cn/problems/remove-duplicates-from-sorted-list/)

```go
func deleteDuplicates(head *ListNode) *ListNode {
	cur := head
	for cur != nil && cur.Next != nil {
		if cur.Val == cur.Next.Val {
			cur.Next = cur.Next.Next
		} else {
			cur = cur.Next
		}
	}
	return head
}
```



## Ⅱ 只保留原链表中只出现一次的元素

题号： BM15, [LC82](https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/description/)

> 需要dummy，因为可能开头就有重复的节点。

法一： 直接移动当前指针删除

```go
func deleteDuplicates(head *ListNode) *ListNode {
	dummy := &ListNode{
		Next: head,
	}
	curr := dummy

	for curr.Next != nil && curr.Next.Next != nil {
        v := curr.Next.Val
		if v == curr.Next.Next.Val {
			for curr.Next != nil && curr.Next.Val == v {
				curr.Next = curr.Next.Next
			}
		} else {
			curr = curr.Next
		}
	}
	return dummy.Next
}
```



法二： 移动临时指针

```python
def deleteDuplicates(self, head: ListNode) -> ListNode:
	dummy = ListNode(0)
	dummy.next = head
	cur = dummy
	while cur.next and cur.next.next:
		v = cur.next.val
		tmp = cur.next.next
		if v == tmp.val:
			while tmp and tmp.val == v:
				tmp = tmp.next
			cur.next = tmp
		else:
			cur = cur.next

	return dummy.next
```
