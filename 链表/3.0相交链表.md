## 两个链表的第一个公共结点

原理：a+b=b+a

```python
def FindFirstCommonNode(self, pHead1, pHead2):
    p1, p2 = pHead1, pHead2
    while p1 != p2:
        if p1 != None:
            p1 = p1.next
        else:
            p1 = pHead2

        if p2 != None:
            p2 = p2.next
        else:
            p2 = pHead1

    return p1		# 不相交时走到None，同样符合题意，妙哉！
```



## 环形链表

```python
def hasCycle(self, head: ListNode) -> bool:
	if head == None:
		return False
		
	fast, slow = head, head
	while fast.next != None and fast.next.next != None:
		slow = slow.next
		fast = fast.next.next
		if slow == fast:
			return True
	return False
```



## 环的入口节点
相遇后：

1. 让 `slow` 回到 `head`
2. `fast` 保持在第一次相遇的位置
3. 两者都改为每次走一步
4. 再次相遇的位置就是**环的入口**

```python
def EntryNodeOfLoop(self, pHead):
    if pHead is None or pHead.next is None:
        return None

    slow = pHead
    fast = pHead

    # 第一阶段：寻找相遇点
    while fast is not None and fast.next is not None:
        slow = slow.next
        fast = fast.next.next

        if slow == fast:
            break
    else:
        # 没有环
        return None

    # 第二阶段：寻找环入口
    slow = pHead

    while slow != fast:
        slow = slow.next
        fast = fast.next

    return slow
```



### 为什么第二次相遇就是入口？

假设：

- `a` = 头节点到环入口的距离
- `b` = 环入口到第一次相遇点的距离
- `c` = 第一次相遇点再绕环回到入口的距离

第一次相遇时：

```
slow 走了：a + b
fast 走了：a + b + k(b + c)
```

由于 `fast` 是 `slow` 的两倍速度：

```
2(a + b) = a + b + k(b + c)
```

所以：

```
a + b = k(b + c)
```

进一步可以得到：

```
a = (k - 1)(b + c) + c
```

也就是说：

> **从头节点走到入口的距离 = 从第一次相遇点继续走到入口的距离（再加若干整圈）。**

因此让一个指针从 `head` 出发，另一个从相遇点出发，并且都每次走一步，它们就会恰好在**环入口**相遇。
