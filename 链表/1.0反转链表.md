## 反转链表

题号：BM1, [LC206](https://leetcode.cn/problems/reverse-linked-list/description/)

### 直接反转

直接反转不需要dummy

```python
def ReverseList(self , head: ListNode) -> ListNode:
    pre = None
    while head != None:
        next = head.next  # 先记住下一个位置，防止断开
        head.next = pre  # 调转方向
        # 往前移动
        pre = head
        head = next
    # head已经了None，所以是返回pre
    return pre
```



### 头插法

需要dummy。反转的第一步都是记录`head.next`。

**核心要义**： 

1. head不变，head将一直被挤到链尾。
2. 需判断head.next是否空，已空意味着head已被挤到链尾。
3. 除了待头插的节点，其它都带有`.next`

```python
def ReverseList(self, head: ListNode) -> ListNode:
    dummy = ListNode(-1)
    dummy.next = head
    while head != None and head.next != None:
        node = head.next    # 记录要头插的节点
        head.next = node.next
        node.next = dummy.next
        dummy.next = node

    return dummy.next
```



### 递归

时间复杂度：O(n)
空间复杂度：O(n)，栈空间等于链表的长度。

```python
def reverseList(self, head: ListNode | None) -> ListNode | None:
    if head == None or head.next == None:
        return head

    # 考虑到链尾了，所以返回的是当前head的next节点
    newHead = self.reverseList(head.next)
    # head是倒数第二个节点，head.next是最后一个节点
    head.next.next = head
    # 相当于把head变成链尾
    head.next = None
    return newHead
```
