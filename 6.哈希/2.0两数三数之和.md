## 两数之和

题号： BM50, [LC1](https://leetcode.cn/problems/two-sum)
时间复杂度： $O(n)$
空间复杂度： $O(n)$

- 如果是有序数组，可以用相向双指针。大了右边-1，小了左边+1。
- 无序数组则使用哈希

Leetcode 版本

```go
func twoSum(nums []int, target int) []int {
    hashTable := map[int]int{}
    for i, x := range nums {
        if v, ok := hashTable[target-x]; ok {
            return []int{v, i}
        }
        hashTable[x] = i
    }
    return nil
}
```

牛客版本（下标+1）

```python
def twoSum(self, numbers: List[int], target: int) -> List[int]:
    dic = {}
    for idx, value in enumerate(numbers):
        find = target - value
        if find in dic:
            return [dic[find] + 1, idx + 1]
        dic[value] = idx
    return []
```




## 三数之和

题号： BM54, [LC15](https://leetcode.cn/problems/3sum)
描述： 返回所有和为 0 且不重复的三元组。
时间复杂度： $O(n\log n + n^2)$，排序$O(n\log n)$，外层循环 \* 两数之和=$O(n^2)$
空间复杂度： O(1)

先排序，后按照相向双指针处理两数之和。

要点：

- 第一层循环到n-2
- 因为数组有序，去重时只要和前后比较即可

```python
def threeSum(self, num: List[int]) -> List[List[int]]:
    num.sort()
    n = len(num)
    ans = []
    for i in range(n - 2):  # -2是j, k各占一个指针
        x = num[i]  # 一轮固定一个数，其他两个数在双指针之间
        # 去重
        if i > 0 and x == num[i - 1]:    # 因为和前一个数(i-1)比较，故有i>0
            continue
        # 优化：最小的三个数相加已经大于0，往后都不可能是0了
        if x + num[i+1] + num[i+2] > 0:
            break
        # 优化：如果x和最大的两个数相加小于0，那么只能是x继续增大
        if x + num[-2] + num[-1] < 0:
            continue
        
        # 相向双指针
        j, k = i + 1, n - 1
        while j < k:
            sum = x + num[j] + num[k]
            if sum < 0:
                j += 1
            elif sum > 0:
                k -= 1
            else:
                ans.append([x, num[j], num[k]])

                # 去重
                j += 1
                k -= 1
                while j < k and num[j] == num[j - 1]:
                    j += 1
                while j < k and num[k] == num[k + 1]:
                    k -= 1

    return ans
```


## 最接近的三数之和

题号： [LC16](https://leetcode.cn/problems/3sum-closest)
描述： 请你从 `nums` 中选出三个在 **不同下标位置** 的整数，使它们的和与 `target` **最接近**。返回这三个数的和。

**思路**： 计算和`target`的绝对值

时间复杂度： $O(n\log n + n^2)$，排序$O(n\log n)$，外层循环 \* 两数之和=$O(n^2)$
空间复杂度： O(1)

```python
def threeSumClosest(self, nums: list[int], target: int) -> int:
    nums.sort()
    n = len(nums)
    closest = float("inf")

    for i in range(n - 2):

        j = i + 1
        k = n - 1

        while j < k:
            s = nums[i] + nums[j] + nums[k]
            if s == target:
                return s

            if abs(s - target) < abs(closest - target):
                closest = s

            if s > target:
                k -= 1
            else:
                j += 1

    return closest
```
