## 两数之和

题号： BM50
时间复杂度： $O(n)$
空间复杂度： $O(n)$

- 如果是有序数组，可以用相向双指针。大了右边-1，小了左边+1。
- 无序数组则使用哈希

Leetcode 版本

```go
func twoSum(nums []int, target int) []int {
    hashTable := map[int]int{}
    for i, x := range nums {
        if v, ok := hashTable[target-x]; ok {
            return []int{v, i}
        }
        hashTable[x] = i
    }
    return nil
}
```

牛客版本（下标+1）

```python
def twoSum(self, numbers: List[int], target: int) -> List[int]:
    dic = {}
    for idx, value in enumerate(numbers):
        find = target - value
        if find in dic:
            return [dic[find] + 1, idx + 1]
        dic[value] = idx
    return []
```




## 三数之和

题号： BM54
时间复杂度： $O(n\log n + n^2)$
空间复杂度： O(1)

先排序，后按照相向双指针处理两数之和。

要点：

- 第一层循环到n-2

```python
def threeSum(self, num: List[int]) -> List[List[int]]:
    num.sort()
    n = len(num)
    ans = []
    for i in range(n - 2):  # -2是jk
        # 去重
        x = num[i]
        if i > 0 and x == num[i - 1]:    # 因为和前一个数(i-1)比较，故有i>0
            continue
				# 优化：最小的三个数相加已经大于0，往后都不可能是0了
        if x + num[i+1] + num[i+2] > 0:
          	break
        # 优化：如果x和最大的两个数相加小于0，那么只能是x继续增大
        if x + num[-2] + num[-1] < 0:
        		continue
        
        # 相向双指针
        j, k = i + 1, n - 1
        while j < k:
            sum = x + num[j] + num[k]
            if sum < 0:
                j += 1
            elif sum > 0:
                k -= 1
            else:
                ans.append([x, num[j], num[k]])

                # 去重
                j += 1
                k -= 1
                while j < k and num[j] == num[j - 1]:
                    j += 1
                while j < k and num[k] == num[k + 1]:
                    k -= 1

    return ans
```
