## 链表中倒数第k个节点

题号： BM8

```python
def FindKthToTail(self, pHead: ListNode, k: int) -> ListNode:
    latter, former = pHead, pHead
    for _ in range(k):
        if former == None:
            return None
        former = former.next

    while former != None:
        latter = latter.next
        former = former.next

    return latter
```



## 删除链表的倒数第 n 个节点

题号： BM9， [LC19](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/)

```python
def removeNthFromEnd(self, head: ListNode | None, n: int) -> ListNode | None:
    dummy = ListNode(next=head)
    # latter在dummy，这样让latter停在要删除的节点前
    latter = dummy
    former = head
    for _ in range(n):
        former = former.next

    while former != None:
        latter = latter.next
        former = former.next
    # 跳过要删除的节点
    latter.next = latter.next.next
    return dummy.next
```
