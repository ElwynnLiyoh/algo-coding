## 回文链表

题号： BM13，[LC234](https://leetcode.cn/problems/palindrome-linked-list/description/)
描述： 
思路： 先快慢指针找到中间节点，然后反转mid后面的链表部分，然后对比值是否想等。
从slow从head出发，fast从head.next出发，
偶数时slow在左半部分最后一个节点；奇数时slow是中点，slow.next在中间右边。
**无脑反转slow.next**，反转后的链长度一定不超过另一部分。因此循环判断回文时，只需要判断反转后的串。
时间复杂度： $O(n)$
空间复杂度： $O(1)$

```go
func isPail(head *ListNode) bool {
    slow, fast := head, head.Next
    for fast != nil && fast.Next != nil {
        slow, fast = slow.Next, fast.Next.Next
    }
  
    rev := reverse(slow.Next)
  
    for rev != nil {
        if rev.Val != head.Val {
            return false
        }
        rev, head = rev.Next, head.Next
    }
 
    return true
}
 
func reverse(head *ListNode) *ListNode {
    var pre *ListNode
    for head != nil {
        tmp := head.Next
        head.Next = pre
        pre = head
        head = tmp
    }
    return pre
}
```



```python
class Solution:
	def isPail(self, head: ListNode) -> bool:
        slow, fast = head, head
        while fast != None and fast.next != None:
            slow = slow.next
            fast = fast.next.next
            
        rev = self.reverse(slow.next)
        
        while rev != None:
            if rev.val != head.val:
                return False
            rev = rev.next
            head = head.next
        return True

    def reverse(self, head):
        pre = None
        while head != None:
            tmp = head.next
            head.next = pre
            pre = head
            head = tmp
        return pre
```
