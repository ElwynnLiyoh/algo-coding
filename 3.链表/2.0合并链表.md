## 合并两个已排序的链表

题号： BM13，​[LC21](https://leetcode.cn/problems/merge-two-sorted-lists/description/)
描述： 
思路： 
时间复杂度： $O(n+m)$
空间复杂度： $O(1)$

> 归并时`<=`更好，这样会具有稳定性。

```python
def mergeTwoLists(self, list1: ListNode, list2: ListNode) -> ListNode | None:
	dummy = ListNode()
	cur = dummy
	while list1 and list2:
		if list1.val <= list2.val:
			cur.next = list1
			list1 = list1.next
		else:
			cur.next = list2
			list2 = list2.next
		cur = cur.next

	cur.next = list1 if list1 else list2
	return dummy.next
```



## 合并k个已排序的链表

题号： BM5，[LC23](https://leetcode.cn/problems/merge-k-sorted-lists/)
描述： 
思路： 分解成多个“合并两个已排序链表”

### 顺序合并

时间复杂度： $O(k^2n)$

假设每个链表的最长长度是 n。在第一次合并后，ans 的长度为 n；第二次合并后，ans 的长度为 2×n，第 i 次合并后，ans 的长度为 i×n。第 i 次合并的时间代价是 O(n+(i−1)×n)=O(i×n)，那么总的时间代价为O( (1+k)⋅k/2×n)=O(k^2n)，故渐进时间复杂度为 O(k^2n)。

空间复杂度： $O(1)$

```go
func mergeKLists(lists []*ListNode) (res *ListNode) {
	for _, ls := range lists {
		res = mergeTwo(res, ls)
	}
	return
}

func mergeTwo(l1, l2 *ListNode) *ListNode {
	var dummy *ListNode = new(ListNode)
	cur := dummy
	for l1 != nil && l2 != nil {
		if l1.Val <= l2.Val {
			cur.Next = l1
			l1 = l1.Next
		} else {
			cur.Next = l2
			l2 = l2.Next
		}
		cur = cur.Next
	}
	if l1 != nil {
		cur.Next = l1
	}
	if l2 != nil {
		cur.Next = l2
	}
	return dummy.Next
}

```



### 分治合并

构造平衡二叉树

#### 两两合并（自底向上）

`lists`存储结果，只要大于一组，就说明还没归并完成。

时间复杂度： $O(kn \cdot \log k)$。k个链表，每轮减半，一共$O(logk)$。第一轮合并k/2组，每组O(2n); 第二组合并k/4组，每组O(4n)……总的时间代价$O(sum_{i=1}^{\infty} \frac{k}{2^i} \times 2^in)=O(kn \times \log k)$
空间复杂度： $O(k)$。保存当前轮次的链表头。

```python
class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        if not lists:
            return None

        while len(lists) > 1:
            merged = []

            # 每两个链表合并成一个
            for i in range(0, len(lists), 2):
                if i + 1 < len(lists):
                    merged.append(self.mergeTwoLists(lists[i], lists[i + 1]))
                else:
                    # 此时i+1==len(lists)
                    # 说明len(lists)是奇数个的最后一个
                    merged.append(lists[i])

            lists = merged

        return lists[0]
```

#### 拆半分治（自顶向下）

时间复杂度： $O(kn \cdot \log k)$
空间复杂度： $O(\log k)$。递归栈空间

```python
class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        if not lists:
            return None

        def merge(left: int, right: int) -> ListNode | None:
            if left == right:
                return lists[left]

            mid = (left + right) // 2

            left_list = merge(left, mid)
            right_list = merge(mid + 1, right)

            return self.mergeTwoLists(left_list, right_list)

        return merge(0, len(lists) - 1)
```


### 优先队列（小根堆）

其实就是多路归并

时间复杂度： $O(kn \cdot \log k$)。队列无素不超k个，插入和删除时间都是$O(\log k)$，最多kn个节点，每个节点都插入删除各一次，故总的渐进时间复杂度为$O(kn*\log k)$
空间复杂度： $O(k)$。队列无素不超k个。

由于ListNode没有比较操作，所以需要加入index用于val相同时的第二比较依据，并且不会出现相同的情况。

```python
import heapq
class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        heap = []

        # 每条链表只把当前最小节点放入堆
        for index, node in enumerate(lists):
            if node:
                heapq.heappush(heap, (node.val, index, node))

        dummy = ListNode(0)
        tail = dummy

        while heap:
            # index代表第几路的归并
            _, index, node = heapq.heappop(heap)

            # 接到结果链表
            tail.next = node
            tail = node

            # 当前链表还有节点，则把下一个节点加入堆
            if node.next:
                heapq.heappush(
                    heap,
                    (node.next.val, index, node.next)
                )

        return dummy.next
```

Python 可以通过定义 `__lt__`，让堆可以比较节点大小。

```python
import heapq
ListNode.__lt__ = lambda a, b: a.val < b.val  # 让堆可以比较节点大小
class Solution:
    def mergeKLists(self, lists: List[ListNode]) -> ListNode:
        cur = dummy = ListNode(0)  # 哨兵节点，作为合并后链表头节点的前一个节点
        h = [head for head in lists if head]  # 初始把所有链表的头节点入堆
        heapq.heapify(h)  # 堆化
        while h:  # 循环直到堆为空
            node = heapq.heappop(h)  # 剩余节点中的最小节点
            if node.next:  # 下一个节点不为空
                heapq.heappush(h, node.next)  # 下一个节点有可能是最小节点，入堆
            cur.next = node  # 合并到新链表中
            cur = cur.next  # 准备合并下一个节点
        return dummy.next  # 哨兵节点的下一个节点就是新链表的头节点
```
