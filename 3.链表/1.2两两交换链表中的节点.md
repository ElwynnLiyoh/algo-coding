## 两两交换链表中的节点

题号： [LC24](https://leetcode.cn/problems/swap-nodes-in-pairs/description)
描述： 给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。

### 迭代

思路： 记录前置节点，用于向后连接，故需要`dummy`。
时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
# 写法一
def swapPairs(self, head: ListNode | None) -> ListNode | None:
    if not head:
        return head

    left, right = head, head.next

    pre = dummy = ListNode(next=head)

    while right:
        left.next = right.next
        right.next = left

        pre.next = right
        pre = left

        if left.next:
            left = left.next
            right = left.next
        else:
            break

# 写法二
def swapPairs(self, head: ListNode | None) -> ListNode | None:
        if not head:
            return head

        pre = dummy = ListNode(next=head)

        while pre.next and pre.next.next:
            left = pre.next
            right = left.next

            left.next = right.next
            right.next = left

            pre.next = right
            pre = left

        return dummy.next
```


### 递归

时间复杂度： $O(n)$
空间复杂度： $O(n)$，栈空间。每两个节点递归一次。

```python
# 写法一（易懂）
def swapPairs(self, head: ListNode | None) -> ListNode | None:
    # 0 个或 1 个节点，不需要交换
    if not head or not head.next:
        return head

    first = head
    second = head.next

    # 递归处理剩余链表
    first.next = self.swapPairs(second.next)

    # 交换前两个节点
    second.next = first

    # second 成为这一组的新头节点
    return second
    
# 写法二（简洁）
def swapPairs(self, head: ListNode | None) -> ListNode | None:
	if not head or not head.next:
		return head

	newHead = head.next
	head.next = self.swapPairs(newHead.next)
	newHead.next=head

	return newHead
```
