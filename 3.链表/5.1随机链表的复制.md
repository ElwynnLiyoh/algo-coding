## 随机链表的复制

题号： [LC138](https://leetcode.cn/problems/copy-list-with-random-pointer/description)
描述： 深拷贝一个带随机指向的链表。

### 哈希

思路： 原节点作链，新节点作值。
时间复杂度： $O(2n)$, 2轮遍历
空间复杂度： $O(n)$

```python
def copyRandomList(self, head: Node | None) -> Node | None:
    if not head:
        return None

    # old_to_new[原节点] = 新节点
    old_to_new = {}

    # 第一遍：只复制节点，不处理指针
    cur = head
    while cur:
        old_to_new[cur] = Node(cur.val)
        cur = cur.next

    # 第二遍：建立 next 和 random
    cur = head
    while cur:
        new_node = old_to_new[cur]

        new_node.next = old_to_new.get(cur.next)
        new_node.random = old_to_new.get(cur.random)

        cur = cur.next

    return old_to_new[head]
```


### 节点穿插法

思路： 新节点穿插在原节点后，构建random，拆分两链表（奇偶重排）。
时间复杂度： $O(3n)$，3轮遍历
空间复杂度： $O(1)$

```python
class Solution:
    def copyRandomList(self, head: "Optional[Node]") -> "Optional[Node]":
        if not head:
            return head

        # 1. 复制各节点，并构建拼接链表
        cur = head
        while cur:
            copy = Node(cur.val)
            copy.next = cur.next
            cur.next = copy
            cur = copy.next

        # 2. 构建各新节点的 random 指向
        cur = head
        while cur:
            copy = cur.next
            if cur.random:
                copy.random = cur.random.next
            cur = copy.next

        # 3. 拆分奇偶链表
        odd, even = head, head.next
        evenh = even  # 待返回的偶数头节点
        while even and even.next:
            odd.next = even.next
            odd = odd.next

            even.next = odd.next
            even = even.next

        return evenh
```

### 哈希+递归

思路： 本质当成有向图。
时间复杂度： $O(n)$
空间复杂度： $O(n+n)$，哈希表+递归栈

```python
class Solution:
    def copyRandomList(self, head: "Optional[Node]") -> "Optional[Node]":
        if not head:
            return head
        
        # old to new
        o2n = {}

        def dfs(cur):
            if not cur:
                return None

            if cur in o2n:
                return o2n.get(cur)

            # 存入新节点
            copy = Node(cur.val)
            o2n[cur] = copy

            # 递归函数返回复制后的新节点，故可以直接连接
            copy.next = dfs(cur.next)
            # 因为是递归先处理next，故所有节点都已存入字典
            # copy.random = dfs(cur.random) # 也可
            copy.random = o2n.get(cur.random)
            return copy

        return dfs(head)
```
