## 在排序数组中查找元素的第一个和最后一个位置

题号： [LC34](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array)
描述： 给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

思路： 注意二分时不能找到就返回，因为需要左边界。找右边界可以是找`target+1`的左边界`-1`。

时间复杂度： $O(\log n)$
空间复杂度： $O(1)$

```python
def lower_bound(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left

class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        start = lower_bound(nums, target)
        if start == len(nums) or nums[start] != target:
            return [-1, -1]
        end = lower_bound(nums, target + 1) - 1
        return [start, end]
```
