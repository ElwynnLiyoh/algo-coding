## 盛最多水的容器

题号： NC168，[LC11](https://leetcode.cn/problems/container-with-most-water/)

双向双指针，贪心策略。

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
def maxArea(self, height: List[int]) -> int:
    left, right = 0, len(height) - 1
    ans = 0
    while left < right:
        area = (right - left) * min(height[right], height[left])
        ans = max(ans, area)
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return ans
```
