## 寻找峰值

题号： BM19，[LC162](https://leetcode.cn/problems/find-peak-element)
时间复杂度： $O(logN)$
空间复杂度： $O(1)$

上坡一定能找到峰值，下坡可能有峰值。所以应该往上走。

```python
def findPeakElement(self, nums: List[int]) -> int:
    left, right = 0, len(nums) - 1
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] > nums[mid + 1]:  # 往右是下坡，未必有峰值
            right = mid
        else:   # 往右是上坡，一定有峰值
            left = mid + 1

    return left
```



```python
def findPeakElement(self, nums: List[int]) -> int:
	left, right = - 1, len(nums) - 1
	while left + 1 < right:
		mid = left + (right - left) // 2
		if nums[mid] > nums[mid + 1]: 
			right = mid
		else: 
			left = mid

	return right
```



## 旋转数组的最小数字

题号： BM21，[LC154](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array-ii/)
描述： 有一个长度为 n 的非降序数组，比如[1,2,3,4,5]，将它进行旋转，即把一个数组最开始的若干个元素搬到数组的末尾，变成一个旋转数组，比如变成了[3,4,5,1,2]，或者[4,5,1,2,3]这样的。请问，给定这样一个旋转数组，求数组中的最小值。
时间复杂度： O(logN)
空间复杂度： O(1)

始终是`mid`和`right`比较。

```go
func minNumberInRotateArray(nums []int) int {
	left, right := 0, len(nums)-1
	for left < right {
		mid := left + (right-left)/2
		// 每次比较mid和右端点的值
		if nums[mid] > nums[right] {
			//mid、right位于两段，最小值在右侧[mid+1,right]
			left = mid + 1
		} else if nums[mid] < nums[right] {
			//mid、right位于一段，最小值在左侧[left,mid]，不排除最小值就是mid
			right = mid
		} else {
			// 两端或一段都可能，只能将 right 指针左移一位
			right--
		}
	}
	# 此时 left == right
	return nums[left]
}
```
