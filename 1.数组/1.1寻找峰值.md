## 寻找峰值

题号： BM19，[LC162](https://leetcode.cn/problems/find-peak-element)
时间复杂度： $O(logN)$
空间复杂度： $O(1)$

上坡一定能找到峰值，下坡可能有峰值。所以应该往上走。

```python
def findPeakElement(self, nums: List[int]) -> int:
    left, right = 0, len(nums) - 1
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] > nums[mid + 1]:  # 往右是下坡，未必有峰值
            right = mid
        else:   # 往右是上坡，一定有峰值
            left = mid + 1

    return left
```



```python
def findPeakElement(self, nums: List[int]) -> int:
	left, right = - 1, len(nums) - 1
	while left + 1 < right:
		mid = left + (right - left) // 2
		if nums[mid] > nums[mid + 1]: 
			right = mid
		else: 
			left = mid

	return right
```
