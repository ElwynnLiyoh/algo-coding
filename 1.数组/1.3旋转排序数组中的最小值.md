## 旋转排序数组的最小值I

题号： [LC153(不同元素)](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array)
描述： 有一个长度为 n 的非降序数组，比如[1,2,3,4,5]，将它进行旋转，即把一个数组最开始的若干个元素搬到数组的末尾，变成一个旋转数组，比如变成了[3,4,5,1,2]，或者[4,5,1,2,3]这样的。请问，给定这样一个旋转数组，求数组中的最小值。

**思路**：最后一个要么是最小值，要么在最小值右侧。因此可以是始终`mid`和`-1`比较（LC153）。

时间复杂度： O(logN)
空间复杂度： O(1)

```python
def findMin(self, nums: list[int]) -> int:
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) >> 1
        # 每次比较mid和右端点的值
        if nums[mid] > nums[-1]:
            # mid、right位于两段，最小值在右侧[mid+1,right]
            left = mid + 1
        else:
            right = mid
	# 此时 left == right
    return nums[left]
```



## 旋转排序数组的最小值II

题号： BM21，[LC154(含重复元素)](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array-ii)

**思路**：这里必须和`right`比较。

时间复杂度： O(logN)
空间复杂度： O(1)

```python
def findMin(self, nums: list[int]) -> int:
	left, right = 0, len(nums) - 1
	while left < right:
		mid = (left + right) >> 1
        # 和右边比较
		if nums[mid] > nums[right]:
			left = mid + 1
		elif nums[mid] < nums[right]:
            # mid、right位于一段，最小值在左侧[left,mid]，不排除最小值就是mid
			right = mid
		else:
            # 两段或一段都可能，只能将 right 指针左移一位
			right -= 1
	return nums[left]
```
