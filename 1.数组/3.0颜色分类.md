## 3.0颜色分类(荷兰国旗问题)

题号： NC212，[LC75](https://leetcode.cn/problems/sort-colors/description/)
描述： 给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums` ，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。我们使用整数 0、 1 和 2 分别表示红色、白色和蓝色。

### 三指针（三路快排）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

注意左右两边对mid的处理不同。
和左边交换时，mid要增加1，因为交换过来的元素不是0就是1, 都已经处理过了。
和右边交换时，mid不需要减少1，因为交换过来的元素还没处理过。

循环条件： mid <= right

```python
def sortColors(self, nums: list[int]) -> None:
    # 分别指向0，1，2区域
    left, mid, right = 0, 0, len(nums) - 1
    # mid是活动指针
    while mid <= right:
        if nums[mid] == 0:  # 说明要交换到0区
            nums[left], nums[mid] = nums[mid], nums[left]
            mid += 1
            left += 1
        elif nums[mid] == 1:  # 正好
            mid += 1
        else:  # 否则交换到2区
            nums[right], nums[mid] = nums[mid], nums[right]
            right -= 1
```



```go
func sortColor(colors []int) []int {
    left, i, right := 0, 0, len(colors)-1

    for i <= right {
        if colors[i] == 0 {
            colors[i], colors[left] = colors[left], colors[i]
            left++
            i++
        } else if colors[i] == 2 {
            colors[i], colors[right] = colors[right], colors[i]
            right--
          	//注意这里没有i++
        } else {
            // colors[i] == 1
            i++
        }
    }

    return colors
}
```

### 染色法

时间复杂度： $O(n)$
空间复杂度： $O(1)$

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        # p0：下一个 0 应该放置的位置
        # p1：下一个 1 应该放置的位置
        #
        # 始终维护：
        # [0, p0)  → 0
        # [p0, p1) → 1
        # [p1, i]  → 2
        p0 = p1 = 0

        for i, x in enumerate(nums):
            # 先把当前位置放成 2。
            #
            # 因为 x 已经保存了原来的值，
            # 如果 x 是 0 或 1，下面会再把它们
            # 写到 p0 / p1 对应的位置。
            nums[i] = 2

            # x == 1 或 x == 0 时，
            # 都需要增加一个 1。
            #
            # 对于 x == 0：
            # 这里先放一个 1，p1 向右移动；
            # 后面的 if 再把 0 放到 p0。
            if x <= 1:
                nums[p1] = 1
                p1 += 1

            # 如果当前元素是 0，
            # 就把 0 放到当前 0 区域的末尾。
            if x == 0:
                nums[p0] = 0
                p0 += 1
```
