## 4.1接雨水

题号： BM94，[LC42](https://leetcode.cn/problems/trapping-rain-water/)

法一法二计算上方水柱高度;
法三单调栈横着算面积。

### 法一： 前后缀分解

时间复杂度： $O(3n)$
空间复杂度： $O(n)$

`[3,1,2,5,2,4]` 前缀最大值为 `[3,3,3,5,5,5]`，后缀最大值为 `[5,5,5,5,4,4]`。

```python
def maxWater(self, arr: List[int]) -> int:
    length = len(arr)
    preMax, sufMax = [0] * length, [0] * length
    preMax[0], sufMax[-1] = arr[0], arr[-1]

    for i in range(1, length):
        preMax[i] = max(preMax[i - 1], arr[i])  # i-1保存了前缀最大值
    for i in range(length - 2, -1, -1):   # 注意循环条件
        sufMax[i] = max(sufMax[i + 1], arr[i])  # i+1保存了后缀最大值

    ans = 0
    for i in range(length):
        ans += min(preMax[i], sufMax[i]) - arr[i]
    # Pythonic
    # for pre, suf, height in zip(preMax, sufMax, arr):
    #     ans += min(pre, suf) - height
    return ans
```



### 法二： 相向双指针（最优解）

时间复杂度： $O(n)$
空间复杂度： $O(1)$

就是将前缀和后缀最大值从数组改成了仅记录一个最大值。
指针相向而动，每次移动小的指针。

```python
# 写法一
def maxWater(self, arr: List[int]) -> int:
    left, right = 0, len(arr) - 1
    preMax, sufMax = 0, 0
    ans = 0
    while left < right:
        preMax = max(preMax, arr[left])
        sufMax = max(sufMax, arr[right])
        # 移动小的指针
        if preMax < sufMax:
            ans += preMax - arr[left]
            left += 1
        else:
            ans += sufMax - arr[right]
            right -= 1

    return ans

# 写法二（减少非必要计算）
def trap(self, height: list[int]) -> int:
    ans = 0
    stack = []

    preMax, sufMax = height[0], height[-1]
    i, j = 0, len(height) - 1

    while i < j:
        if preMax < sufMax:
            ans += preMax - height[i]
            i += 1
            preMax = max(preMax, height[i])
        else:
            ans += sufMax - height[j]
            j -= 1
            sufMax = max(sufMax, height[j])

    return ans
```



### 法三： 单调栈

其实就是横着算面积。
从左往右，栈内是还没有找到右边界的低洼柱子的下标。
用的是**单调递减栈**。
`height[stack[-1]] < height[i]`出栈条件`<=`也可以，等高柱计算面积为0。

时间复杂度： $O(n)$
空间复杂度： $O(n)$

```python
def trap(self, height: list[int]) -> int:
    ans = 0
    stack = []

    for i in range(len(height)):
        # 当前柱子比栈顶高，说明找到了栈顶柱子的右边界
        while stack and height[stack[-1]] < height[i]:
            # 凹槽位置
            bottom = stack.pop()

            # 栈为空，说明没有左边界，无法形成凹槽
            if not stack:
                break
                
            # 左右边界
            left = stack[-1]
            right = i
            
            # 左右边界之间的宽度width
            w = right - left - 1
            # 水面的高度由较矮的左右边界决定
            h = min(height[left], height[right]) - height[bottom]

            ans += w * h

        stack.append(i)
        
    return ans
```
