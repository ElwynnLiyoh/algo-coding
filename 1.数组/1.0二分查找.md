## 二分查找-1
题号： BM1
时间复杂度： O()
空间复杂度： O()

左闭右闭 [left, right]

找不到：
	left = mid + 1
	right = mid - 1

循环：
    left <= right

```python
def search(self, nums: List[int], target: int) -> int:
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) >> 1
        # mid = left + (right - left >> 1)  # 注意括号
        # mid = (left + right) // 2 
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

> [! warning]
> Python、Jvav、go中加法优先级高于位移。故
> `mid = left + (right - left >> 1) `
