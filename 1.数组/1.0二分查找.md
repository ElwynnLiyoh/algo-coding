## 二分查找-1

题号： BM1，[LC704](https://leetcode.cn/problems/binary-search/description/)，[LC35（变种）](https://leetcode.cn/problems/search-insert-position/)
时间复杂度： $O(\log n)$
空间复杂度： $O(1)$

注意右区间和循环条件

```python
class Solution:
    # 推荐：左闭右开 `[left, right)`
    def search(self, nums: list[int], target: int) -> int:
        l, r = 0, len(nums)
        while l < r:
            mid = (l + r) >> 1
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                l = mid + 1
            else:
                r = mid
                
        return -1

    # 左闭右闭 `[left, right]`
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1

        while left <= right:
            mid = (left + right) >> 1
            # mid = left + (right - left >> 1)  # 注意括号
            # mid = (left + right) // 2 
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1

        return -1
```

> [! warning]
> Python、Jvav、go中加法优先级高于位移。故
> `mid = left + (right - left >> 1) `


## [二分查找-2](https://www.nowcoder.com/practice/4f470d1d3b734f8aaf2afb014185b395)

描述：升序数组找第一个target
时间复杂度： $O(\log n)$
空间复杂度：$O(1)$

左闭右开 `[left, right)`

```plaintext
< target | >= target
---------|----------
         ↑
       答案
```

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums)

        while l < r:
            mid = (l + r) >> 1
            # mid 以及它左边的所有位置，都不可能是第一个 >= target 的位置。
            # 故直接mid+1
            if nums[mid]<target:
                l = mid + 1
            # nums[mid] >= target, mid可能是答案
            else:
                r = mid
        
        # 循环跳出时 l == r
        # left 是第一个 >= target 的位置
        if l < len(nums) and nums[l] == target:
            return l

        return -1 
```
