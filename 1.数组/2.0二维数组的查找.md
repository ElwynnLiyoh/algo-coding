## 二维数组的查找

题号： BM2，[LC240](https://leetcode.cn/problems/search-a-2d-matrix-ii/description/)
时间复杂度： $O(n+m)$
空间复杂度： $O(1)$

最优解：从左下角开始查找

```python
def Find(self, target: int, array: List[List[int]]) -> bool:
    i, j = len(array) - 1, 0
    while i >= 0 and j < len(array[0]):  # 注意j的判断长度 len(array[0])
        if array[i][j] == target:
            return True
        elif array[i][j] < target:
            j += 1
        else:
            i -= 1
    return False
```

也可以逆时针旋转45度，当成二叉搜索树查找。
即从右上角开始查找。

```python
def Find(self, target: int, array: List[List[int]]) -> bool:
        i, j = 0, len(array[0]) - 1
        while i <len(array) and j >=0:
            if array[i][j] == target:
                return True
            elif array[i][j] < target:
                i+=1
            else:
                j-=1
        return False
```

## 搜索二维矩阵

题号： BM2，[LC74](https://leetcode.cn/problems/search-a-2d-matrix/description//)

看成一维矩阵。对于`m`行`n`列，有
$$
a[i]=matrix[i//n][i \% m]
$$

时间复杂度： $O(\log(m+n))$
空间复杂度： $O(1)$

```python
def searchMatrix(self, matrix: list[list[int]], target: int) -> bool:
    m, n = len(matrix), len(matrix[0])
    left, right = 0, m * n
    while left < right:
        mid = (left + right) // 2
        x = matrix[mid // n][mid % n]
        if x == target:
            return True
        if x < target:
            left = mid + 1
        else:
            right = mid
    return False
```
