| 排序   | 时间复杂度        | 空间       | 稳定  |
| ---- | ------------ | -------- | --- |
| 冒泡排序 | O(n²)        | O(1)     | ✅   |
| 插入排序 | O(n²)        | O(1)     | ✅   |
| 选择排序 | O(n²)        | O(1)     | ❌   |
| 快速排序 | O(n log n)平均 | O(log n) | ❌   |
| 堆排序  | O(n log n)   | O(1)     | ❌   |
| 归并排序 | O(n log n)   | O(n)     | ✅   |
