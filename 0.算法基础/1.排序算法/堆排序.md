## 堆排序

[LC912](https://leetcode.cn/problems/sort-an-array/description/)

### 下标关系

```plaintext
        0
      /   \
     1     2
    / \   / \
   3   4 5   6
```

```plaintext
left  = 2 * i + 1
right = 2 * i + 2
parent = (i - 1) // 2
```

大根堆：根>=左、右
小根堆：根<=左、右

堆排序实际上只有两个阶段：

```plaintext
                 Heap Sort
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
       建大根堆             不断取最大值
          │                   │
   从最后非叶子节点开始       交换 0 和 end
   从后往前 heapify           ↓
                              缩小堆
                                ↓
                              heapify(0)
```



| 操作         | 时间               | 补充     |
| ---------- | ---------------- | ------ |
| 建堆         | `O(n)`           | 不超`4n` |
| 每次取最大值     | `O(log n)`       |        |
| 共取 `n-1` 次 | `O(n log n)`     |        |
| 总计         | **`O(n log n)`** |        |
| 额外空间       | **`O(1)`**       |        |



### 大根堆

```python
class Solution:
    def sortArray(self, nums: list[int]) -> list[int]:
        n = len(nums)

        # 1. 建立大根堆
        # n // 2 - 1 是最后一个非叶子节点
        for i in range(n // 2 - 1, -1, -1):
            self.heapify(nums, n, i)

        # 2. 每次把堆顶最大值放到数组末尾
        for end in range(n - 1, 0, -1):
            # 交换后堆顶已不是大根堆
            nums[0], nums[end] = nums[end], nums[0]

	        # end 之前仍然是堆，end 及之后已经排好序
	        self.heapify(nums, end, 0)

        return nums

    # 这里的 n 不是数组长度，而是当前堆的有效长度。
    def heapify(self, nums: list[int], n: int, i: int) -> None:
        while True:
            largest = i  # 记录最大值下标
            left = 2 * i + 1
            right = 2 * i + 2

            # 找父节点、左孩子、右孩子中的最大值
            if left < n and nums[left] > nums[largest]:
                largest = left

            if right < n and nums[right] > nums[largest]:
                largest = right

            # 当前节点已经最大，堆性质满足
            if largest == i:
                break

            # 把最大值换到当前节点
            nums[i], nums[largest] = nums[largest], nums[i]

            # 被换下去的元素可能继续破坏下面的堆，需要下坠，下一轮继续处理
            i = largest
```
