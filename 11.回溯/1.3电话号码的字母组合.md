## 电话号码的字母组合

题号：[LC17](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)
描述：给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。
![示例图](https://pic.leetcode.cn/1752723054-mfIHZs-image.png)
思路：
时间复杂度： $O(3^m*4^n)$，m为3个字母的按键数量，n为4个字母的按键数量。
空间复杂度： $O(m+n)$

```python
class Solution:
    def letterCombinations(self, digits: str) -> list[str]:
        if not digits:
            return []

        phone = {
            "2": "abc",
            "3": "def",
            "4": "ghi",
            "5": "jkl",
            "6": "mno",
            "7": "pqrs",
            "8": "tuv",
            "9": "wxyz",
        }

        ans: List[str] = []
        path: List[str] = []

        def backtrack(index: int) -> None:
            # 所有数字都处理完，得到一个完整组合
            if index == len(digits):
                ans.append("".join(path))
                return

            # 当前数字对应的所有字母
            letters = phone[digits[index]]

            for letter in letters:
                # 做选择
                path.append(letter)
                # 处理下一个数字
                backtrack(index + 1)
                # 撤销选择
                path.pop()

        backtrack(0)
        return ans
```
