## 1.2字符串全排列

题号： BM58
描述： 输入一个长度为 n 字符串，打印出该字符串中字符的所有排列，你可以以任意顺序返回这个字符串数组。例如输入字符串ABC,则输出由字符A,B,C所能排列出来的所有字符串ABC,ACB,BAC,BCA,CBA和CAB。
思路： 
时间复杂度： $O(n!)$
空间复杂度： $O(n!)$

写法一

```python
class Solution:
    def Permutation(self, ss):
        ss = sorted(ss)
        n = len(ss)

        ans = []
        path = []
        used = [False] * n

        def backtrack():
            if len(path) == n:
                ans.append(''.join(path))
                return

            for i in range(n):
                if used[i]:
                    continue

                # 同一层跳过重复字符
                if i > 0 and ss[i] == ss[i - 1] and not used[i - 1]:
                    continue

                path.append(ss[i])
                used[i] = True

                backtrack()

                used[i] = False
                path.pop()

        backtrack()
        return ans
```



写法二

```python
class Solution:
    def Permutation(self, s: str) -> List[str]:
        n = len(s)

        if n == 0:
            return [""]

        path = [""] * n
        ans = []
        used = [False] * n
        s = sorted(s)

        def dfs(depth):
            nonlocal path

            if depth == n:
                ans.append("".join(path))
                return

            for i in range(n):
                if used[i]:
                    continue

                if i > 0 and s[i] == s[i - 1] and used[i - 1] == False:
                    continue

                # 做选择
                path[depth] = s[i]
                used[i] = True

                dfs(depth + 1)

                # 撤销选择
                used[i] = False

        dfs(0)
        return ans
```
