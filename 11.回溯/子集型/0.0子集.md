## 子集

题号：[LC78](https://leetcode.cn/problems/subsets)
描述：给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

### 回溯

时间复杂度： $O(n×2^n)$。一共 $2^n$ 个状态，每种状态需要 *O*(*n*) 的时间来构造子集。
空间复杂度： $O(n)$。临时数组 *t* 的空间代价是 *O*(*n*)，递归时栈空间的代价为 *O*(*n*)。

```python
class Solution:
    # 法一
    def subsets(self, nums: list[int]) -> list[list[int]]:
        ans = []
        path = []

        def dfs(cur: int) -> None:
            if cur == len(nums):
                # 复制当前 path，保存当前子集
                ans.append(path.copy())
                return

            # 选择 nums[cur]
            path.append(nums[cur])
            dfs(cur + 1)

            # 撤销选择
            path.pop()
            # 不选择 nums[cur]
            dfs(cur + 1)

        dfs(0)
        return ans
    
    # 法二
    def subsets(self, nums: list[int]) -> list[list[int]]:
        ans = []
        path = []

        def backtrack(start: int) -> None:
            # 当前 path 本身就是一个合法子集。可以是空集
            # 保存的是当前状态的快照。
            ans.append(path.copy())

            for i in range(start, len(nums)):
                # 选择 nums[i]
                path.append(nums[i])
                # 继续选择后面的元素
                backtrack(i + 1)
                # 撤销选择
                path.pop()

        backtrack(0)
        return ans
```

### 二进制迭代

关键：`mask & (1 << i)`

例如：`101`

```plaintext
1：选 nums[0]
0：不选 nums[1]
1：选 nums[2]
```

时间复杂度： $O(n × 2^n)$
空间复杂度： $O(n)$

```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        n = len(nums)
        ans = []

        # 一共有 2^n 种选择状态
        for mask in range(1 << n):
            subset = []

            # 检查 nums[i] 是否被选中
            for i in range(n):
                if mask & (1 << i):
                    subset.append(nums[i])

            ans.append(subset)

        return ans
```



## 子集II

题号：[LC90](https://leetcode.cn/problems/subsets-ii)
描述：**有重复**
思路：先排序，这样重复的元素就会排在一起。
时间复杂度： $O()$
空间复杂度： $O()$

### 回溯

```python
class Solution:
	# 法一
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        ans = []
        path = []

        def dfs(cur: int) -> None:
            if cur == len(nums):
                ans.append(path.copy())
                return

            # 选择当前元素
            path.append(nums[cur])
            dfs(cur + 1)
            path.pop()

            # 不选择当前元素(前面已经选择过了)
            # 如果后面是相同元素，全部跳过
            while cur + 1 < len(nums) and nums[cur] == nums[cur + 1]:
                cur += 1
            dfs(cur + 1)

        dfs(0)
        return ans
    
    # 法二
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        ans = []
        path = []

        def backtrack(start: int) -> None:
            # 每到一个节点，当前 path 都是一个合法子集
            ans.append(path.copy())

            # 枚举当前层可以选择的元素
            for i in range(start, len(nums)):
                # 同一层中，如果当前元素和前一个元素相同，
                # 说明选择 nums[i] 会产生重复结果
                if i > start and nums[i] == nums[i - 1]:
                    continue

                # 选择 nums[i]
                path.append(nums[i])

                # 下一层只能从 i + 1 开始选择
                backtrack(i + 1)

                # 撤销选择
                path.pop()

        backtrack(0)
        return ans
```

### 二进制迭代

```python
class Solution:
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        n = len(nums)
        ans = []

        for mask in range(1 << n):
            subset = []
            valid = True

            for i in range(n):
                if mask & (1 << i):
                    # 当前元素和前一个元素相同，
                    # 但前一个元素没有被选中，
                    # 说明当前元素是“重复产生”的选择方式
                    if i > 0 and nums[i] == nums[i - 1]:
                        if not (mask & (1 << (i - 1))):
                            valid = False
                            break

                    subset.append(nums[i])

            if valid:
                ans.append(subset)

        return ans
```
