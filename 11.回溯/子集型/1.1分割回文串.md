## 分割回文串

题号：[LC131](https://leetcode.cn/problems/palindrome-partitioning)
描述：给你一个字符串 `s`，请你将 `s` 分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。
思路：
时间复杂度：  $O(n×2^n)$。
空间复杂度： $O(n)$

```python
class Solution:
    # 法一
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        ans = []
        path = []

        def dfs(start, i) -> None:
            # 分割完毕
            if i == len(s):
                ans.append(path.copy())
                return

            # 分割得到子串
            t = s[start : i + 1]
            if t == t[::-1]:
                path.append(t)
                # 现在 s 未被分割的部分为 [i+1, n-1]
                dfs(i + 1, i + 1)
                # 恢复现场
                path.pop()

            # 不分割
            # i=n-1 时必须分割（这是最后一段），i<n-1 时才可以不分割
            if i < n - 1: 
                dfs(start, i + 1)

        dfs(0, 0)
        return ans

    # 法二
    def partition(self, s: str) -> list[list[str]]:
        n = len(s)
        ans = []
        path = []

        def dfs(i):
            if i == n:
                ans.append(path.copy())
                return

            for j in range(i, n):
                # 截取子串
                t = s[i : j + 1]
                if t == t[::-1]:  # 判断是否回文
                    # 扫完才算作一组答案
                    path.append(t)
                    dfs(j + 1)
                    path.pop()

        dfs(0)
        return ans
```
