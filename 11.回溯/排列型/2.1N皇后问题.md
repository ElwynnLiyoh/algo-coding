## N皇后问题

题号： BM59，[LC51](https://leetcode.cn/problems/n-queens)
描述： 
N 皇后问题是指在 n * n 的棋盘上要摆 n 个皇后，  
要求：任何两个皇后不同行，不同列也不在同一条斜线上，  
求给一个整数 n ，返回 n 皇后的摆法数。

思路： 记录几个状态，用于核心剪枝
```python
cols = set()
diag1 = set()   # row - col \ 主对角线
diag2 = set()   # row + col / 副对角线
```
时间复杂度： $O(n!)$, 上界是$O(n^n)$, 但列不能重复，剪枝后是$O(n!)$
空间复杂度： $O(n)$, 这里的空间 `O(n)` 是指**辅助空间**，包括递归栈和三个集合；如果要保存所有棋盘方案，则还需要计算结果本身的空间。

**标准抽象**

完整代码

```python
def Nqueen(self, n: int) -> int:
        cols, diag1, diag2 = set(), set(), set()
        ans = 0

        def dfs(row):
            nonlocal ans
            if row == n:
                ans += 1
                return

            for col in range(n):
                # 剪枝
                if col in cols or row - col in diag1 or col + row in diag2:
                    continue

                # 做选择
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)

                dfs(row + 1)

                # 撤销选择
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)

        dfs(0)
        return ans
```

为什么不需要`rows=set()`? 因为我们在 DFS 的设计中已经**人为规定了“一行只放一个皇后”**，所以 `row` 这个维度天然不会重复。



LC版
```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        ans = []
        board = [['.'] * n for _ in range(n)]

        cols = set()
        diag1 = set()  # row - col：主对角线
        diag2 = set()  # row + col：副对角线

        def dfs(row: int) -> None:
            # 所有行都放置完成
            if row == n:
                ans.append([''.join(r) for r in board])
                return

            for col in range(n):
                # 当前已有皇后
                if col in cols or row-col in diag1 or row+col in diag2:
                    continue

                # 放置皇后
                board[row][col] = 'Q'
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)

                # 处理下一行
                dfs(row + 1)

                # 撤销选择，恢复现场
                board[row][col] = '.'
                cols.remove(col)
                diag1.remove(row - col)
                diag2.remove(row + col)

        dfs(0)
        return ans
```
