## 有重复数字的全排列

题号： BM56
描述： 给出一组可能包含重复项的数字，返回该组数字的所有排列。结果以字典序升序排列。
思路： 排序后，同一层不要重复选择相同的数字。
时间复杂度： $O(n!)$
空间复杂度： $O(n!)$

```python
class Solution:
    def permuteUnique(self, nums: List[int]) -> List[List[int]]:
        nums.sort()  # 先排序
        n = len(nums)
        path = []
        used = [False] * n
        ans = []

        def backtrace():
            if len(path) == n:
                ans.append(path.copy())
                return

            for i in range(n):
                if used[i]:
                    continue

                if i > 0 and nums[i] == nums[i - 1] and used[i - 1] == False:
                    continue

                path.append(nums[i])
                used[i] = True

                backtrace()

                path.pop()
                used[i] = False

        backtrace()
        return ans
```



写法二

```python
class Solution:
    def permuteUnique(self, nums: List[int]) -> List[List[int]]:
        nums.sort()  # 先排序
        n = len(nums)
        path = [0] * n
        used = [False] * n
        ans = []

        def backtrace(cur):
            if cur == n:
                ans.append(path.copy())
                return

            for i in range(n):
                if used[i]:
                    continue

                if i > 0 and nums[i] == nums[i - 1] and used[i - 1] == False:
                    continue

                path[cur] = nums[i]
                used[i] = True

                backtrace(cur + 1)

                used[i] = False

        backtrace(0)
        return ans
```
