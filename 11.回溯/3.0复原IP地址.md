## 复原IP地址

题号： BM74,  LC93
描述： 现在有一个只包含数字的字符串，将该字符串转化成IP地址的形式，返回所有可能的情况。

时间复杂度： $O(n)$，最多切 4 段，每段最多 3 种选择，实际是常数级$O(3^4)$。

空间复杂度： $O(4)$，递归深度。

```python
class Solution:
    def restoreIpAddresses(self, s: str)->List[str]:
        ans = []
        n = len(s)

        def dfs(index, path):
            # 已经4段
            if len(path) == 4:
                # 字符必须全部使用
                if index == n:
                    ans.append(".".join(path))
                return

            # 剩余长度剪枝
            remain = 4 - len(path)	# 剩余IP段
            left = n - index	# 剩余字符
            if left < remain or left > remain * 3:
                return

            # 每段最多3位
            for length in range(1, 4):
                if index + length > n:
                    break
                part = s[index:index+length]

                # 前导0，只能是一位数
                if len(part) > 1 and part[0] == '0':
                    continue
                # 大于255
                if int(part) > 255:
                    continue

                path.append(part)
                dfs(
                    index + length,
                    # path + [part]
                    path
                )
                path.pop()

        dfs(0, [])
        return ans
```

列表相加会创建新列表，可以省去pop操作

```python
                dfs(
                    index + length,
                    path + [part]
                )
```
