## 每日温度

**单调栈**经典题

题号： [LC739](https://leetcode.cn/problems/daily-temperatures/)
描述： 给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

| 遍历方向     | 栈的含义          |
| -------- | ------------- |
| **从左往右** | 等待未来更高温度来解决   |
| **从右往左** | 保存右侧可能成为答案的候选 |

### 从后往前

思路： 用栈保存**可能成为左边元素“下一个更高温度”的下标。**
从前往后的时间视角看，栈顶记录了下次升温的位置。
栈顶始终最小，是单调递减栈。

时间复杂度： $O(n)$，每个元素最多进栈出栈一次。
空间复杂度： $O(n)$

```python
class Solution:
    def dailyTemperatures(self, temperatures: list[int]) -> list[int]:
        n = len(temperatures)
        ans = [0] * n

        # 单调递减栈
        # 栈中存储的是下标，而不是温度
        stack = []

        # 从后往前处理
        for i in range(n - 1, -1, -1):
            # 栈顶温度 <= 当前温度时，
            # 栈顶元素不可能成为当前元素的“下一个更高温度”
            # 同温度也要入栈，因为只需要同温度最左边的
            while stack and temperatures[stack[-1]] <= temperatures[i]:
                stack.pop()

            # 如果栈不为空，
            # 栈顶就是右边第一个比当前温度高的位置
            if stack:
                ans[i] = stack[-1] - i

            # 当前下标加入单调栈
            stack.append(i)

        return ans
```

### 从左往右

思路： 

当前温度还没有找到“下一次升温”，就把它放进栈里等待。
当后面出现一个更高温度时，它就可以解决前面那些更低温度。

栈内是还没有找到更高温度的元素。
依旧是**单调递减栈**。

时间复杂度： $O(n)$，每个元素最多进栈出栈一次。
空间复杂度： $O(n)$

```python
def dailyTemperatures(self, temperatures: list[int]) -> list[int]:
	n = len(temperatures)
	ans = [0] * n
	stack = []

	for i in range(n):
		# 同温度不出栈，因为同温度不算升温
		while stack and temperatures[stack[-1]] < temperatures[i]:
			# 现在出现了更高的温度，可以解决前面那些更低的温度
			prev = stack.pop()
			ans[prev] = i - prev

		stack.append(i)

	return ans
```
