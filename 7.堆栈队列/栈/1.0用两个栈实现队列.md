## 用两个栈实现队列

题号： BM42
描述： 
思路： 
**值得注意的地方**：
1. push时仅插入stack1，不要立即倒入stack2，因为stack2可能还有元素
2. pop时只有当stack2空了才从stack1倒入，并且要一次性全部倒入

时间复杂度： $O(1)$，对于删除操作，虽然看起来是 O(n)O(n) 的时间复杂度，但是仔细考虑下每个元素只会「至多被插入和弹出 stack2 一次」，因此均摊下来每个元素被删除的时间复杂度仍为 O(1)。
空间复杂度： $O(n)$

```python
class Solution:
    def __init__(self):
        self.stack1 = []
        self.stack2 = []

    def push(self, node):
        self.stack1.append(node)

    def pop(self):
        if not self.stack2:
            self.stack2 = self.stack1[::-1]
            self.stack1.clear()
        return self.stack2.pop()
```
