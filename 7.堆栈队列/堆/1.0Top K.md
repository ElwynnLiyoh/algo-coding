## 最小的K个数

题号： BM46
描述： 给定一个长度为 n 的可能有重复值的数组，找出其中不去重的最小的 k 个数

如果K较大，可以利用快排性能好的优势。
K较小的话，冒泡选择堆排序。

### 大根堆

思路：

1. 遍历数组。
2. 把元素放进大根堆。
3. 如果堆大小超过 `k`，删除堆顶，也就是当前最大的元素。
4. 最终堆中剩下的就是最小的 `k` 个数。
   Python 的 `heapq` 只有**小根堆**，所以这里通过取负数模拟大根堆。

时间复杂度： $O(n\log k)$
空间复杂度： $O(k)$

```python
import heapq
class Solution:
    def GetLeastNumbers_Solution(self, input: List[int], k: int) -> List[int]:
        if k <= 0 or k > len(input):
            return []
 
        heap = []
 
        for x in input:
            heapq.heappush(heap, -x)
 
            if len(heap) > k:
                heapq.heappop(heap)
 
        return [-x for x in heap]
```


### 小根堆

堆排序K次即可

```python
import heapq
class Solution:
    def GetLeastNumbers_Solution(self, input: List[int], k: int) -> List[int]:
        if k <= 0 or k > len(input):
            return []

        heapq.heapify(input)
        ans = []
        for _ in range(k):
            ans.append(heapq.heappop(input))
            
        return ans
```

### 快速选择

使用快速排序的思想

时间复杂度： $O(n)$，相比快速排序，只需要处理一边
空间复杂度： $O(1)$

```python
class Solution:
    def GetLeastNumbers_Solution(self, input: List[int], k: int) -> List[int]:
        target = k - 1
        left = 0
        right = len(input) - 1

        while left <= right:
            p = self.partition(input, left, right)
            if p == target:
                return input[:k]
            elif p > target:
                right = p - 1
            else:
                left = p + 1

        return []

    def partition(self, nums, left, right):
        pivot = nums[right]
        i, j = left, right
        while i < j:
            while i < j and nums[i] <= pivot:
                i += 1
            nums[j] = nums[i]
            while i < j and nums[j] >= pivot:
                j -= 1
            nums[i] = nums[j]
        nums[i] = pivot

        return i
```


## 寻找第K大

题号： BM47
描述： 有一个整数数组，请你根据快速排序的思路，找出数组中第 k 大的数。

### 小根堆

| K    | 第 K 大对应第几小 |
| ---- | ----------------- |
| 1    | 第 n 小           |
| 2    | 第 n-1 小         |
| 3    | 第 n-2 小         |
| K    | **第 n-K+1 小**   |

时间复杂度： $O(n+(n-K)\log n$，`heapify` 是 `O(n)`，弹出 `n-K+1` 次，每次 `O(log n)`，总体 `O(n + (n-K)log n)`。
空间复杂度： $O(1)$


```python
import heapq
class Solution:
    def findKth(self, a: List[int], n: int, K: int) -> int:
        k = n - K + 1
        heapq.heapify(a)

        for _ in range(k):
            ans = heapq.heappop(a)
        return ans
```

`ans`无需在for外定义。
这里补充pthon的局部作用域。

| 结构        | 创建新的局部作用域？ |
| --------- | ---------- |
| `if`      | ❌          |
| `for`     | ❌          |
| `while`   | ❌          |
| `with`    | ❌          |
| `try`     | ❌          |
| 函数 `def`  | ✅          |
| 类 `class` | ✅（规则稍特殊）   |
| 推导式 `[]`  | ✅          |



更优的做法：**维持大小为K的小根堆**

时间：$O(n \log K)$，维持大小为K的堆
空间：$O(K)$

```python
import heapq
class Solution:
    def findKth(self, a: List[int], n: int, K: int) -> int:
        heap = []
        for x in a:
            heapq.heappush(heap, x)
            if len(heap) > K:
                # 每次pop最小，留下的即为最大的K个数
                heapq.heappop(heap)
        # heap是有堆性质的列表，heap[0]即堆顶，为K个数中最小的，即输入数组中的第K大
        return heap[0]
```



### 快速选择

时间：$O(n)$，相比快速排序，只需要处理一边。
一个误区是以为处理一边就是$\frac{1}{2}n\log n$，实际上快速选择连半棵树的工作量都没有，实际工作量是树的“一条路径”。正解为 n + n/2 + n/4 + n/8 + ... = 2n。最坏：$O(n^2)$
空间：$O(1)$

以下将“第K大”转换成寻找”第n-K小“
```python
class Solution:
    def findKth(self, a: List[int], n: int, K: int) -> int:
	    # 这里的target不需要n-k+1, 因为target是下标而不是“第几小”
        target = n - K
        left, right = 0, n - 1

        while left <= right:
            p = self.partition(a, left, right)
            if p == target:
                return a[p]
            elif p > target:
                right = p - 1
            else:
                left = p + 1
        return -1

    def partition(self, nums, left, right):
        pivot = nums[right]
        i, j = left, right
        while i < j:
            while i < j and nums[i] <= pivot:
                i += 1
            nums[j] = nums[i]
            while i < j and nums[j] >= pivot:
                j -= 1
            nums[i] = nums[j]
        nums[i] = pivot
        return i
```
