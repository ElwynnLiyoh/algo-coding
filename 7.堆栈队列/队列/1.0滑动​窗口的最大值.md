## 滑动​窗口的最大值

题号： BM45
描述： 

给定一个长度为 n 的数组 num 和滑动窗口的大小 size ，找出所有滑动窗口里数值的最大值。
例如，如果输入数组{2,3,4,2,6,2,5,1}及滑动窗口的大小3，那么一共存在6个滑动窗口，他们的最大值分别为{4,4,6,6,6,5}； 针对数组{2,3,4,2,6,2,5,1}的滑动窗口有以下6个： {[2,3,4],2,6,2,5,1}， {2,[3,4,2],6,2,5,1}， {2,3,[4,2,6],2,5,1}， {2,3,4,[2,6,2],5,1}， {2,3,4,2,[6,2,5],1}， {2,3,4,2,6,[2,5,1]}。
窗口大于数组长度或窗口长度为0的时候，返回空。



### 有序双端队列

思路： 

维护一个双端队列 `deque`，里面存的是**数组下标**，并保证：
```
num[deque[0]] >= num[deque[1]] >= num[deque[2]] ...
```
也就是说，队头永远是当前窗口的最大值。

为什么存下标而不是数值？因为窗口向右移动时，需要知道某个元素是否已经**离开窗口**。

时间复杂度： $O(n)$，即使嵌套循环，但每个元素最多append, pop, popleft一次。
空间复杂度： $O(size)$，窗口大小

```python
from collections import deque
class Solution:
    def maxInWindows(self, num: List[int], size: int) -> List[int]:
        n = len(num)
        ans = []
        if size <= 0 or size > n:
            return ans

        dq = deque()

        for i in range(n):
            # 1. 删除已经离开窗口的元素. 
            # 因为队头是最大值，最大值都离开了，就要立即删除
            while dq and dq[0] < i - size + 1:
                dq.popleft()
            # 2. 删除不可能成为最大值的元素
            # 队尾（窗口的最小值）比当前即将加入的元素还小，那么队尾元素永远不可能成为最大值
            while dq and num[dq[-1]] <= num[i]:
                dq.pop()

            # 3. 加入当前元素
            dq.append(i)

            # 窗口形成后记录最大值
            if i >= size - 1:
                ans.append(num[dq[0]])

        return ans
```



### 堆

核心是使用**大根堆 + 延迟删除（lazy deletion）**

因为堆只能高效删除堆顶，如果过期元素不在堆顶，只能延迟删除。

时间复杂度： $O(n \log size)$
空间复杂度： $O(n)$

```python
import heapq
class Solution:
    def maxInWindows(self, num: List[int], size: int) -> List[int]:
        n = len(num)
        if size <= 0 or size > n:
            return []

        heap = []
        ans = []

        for i in range(n):
            # 大根堆：负数模拟
            heapq.heappush(heap, (-num[i], i))

            # 当前窗口左边界
            left = i - size + 1

            # 删除已经离开窗口的堆顶元素
            while heap and heap[0][1] < left:
                heapq.heappop(heap)

            # 窗口形成后记录最大值
            if i >= size - 1:
                ans.append(-heap[0][0])

        return ans
```
