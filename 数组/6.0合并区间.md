## 合并区间

题号： BM89
描述： 给出一组区间，请合并所有重叠的区间。请保证合并后的区间按区间起点升序排列。
思路： 
时间复杂度： $O(n+ n\log n)$
空间复杂度： $O(val)$

```python
def merge(self, intervals: List[Interval]) -> List[Interval]:
    intervals.sort(key=lambda x: x.start)
    n = len(intervals)
    i = 0
    res = []
    while i < n:
        start = intervals[i].start  # 区间最小值
        end = intervals[i].end  # 区间最大值
        j = i + 1
        while j < n and intervals[j].start <= end:
            if intervals[j].end > end:
                end = intervals[j].end
            j += 1
        res.append(Interval(start, end))
        i = j

    return res
```
