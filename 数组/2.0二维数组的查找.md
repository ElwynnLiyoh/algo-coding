## 二维数组的查找
题号： BM2
时间复杂度： O(n+m)
空间复杂度： O(1)


最优解：从左下角开始查找
```python
def Find(self, target: int, array: List[List[int]]) -> bool:
    i, j = len(array) - 1, 0
    while i >= 0 and j < len(array[0]):  # 注意j的判断长度 len(array[0])
        if array[i][j] == target:
            return True
        elif array[i][j] < target:
            j += 1
        else:
            i -= 1
    return False
```
