## 4.1接雨水

题号： BM94
### 法一： 前后缀分解

时间复杂度： O(n)
空间复杂度： O(n)

[3,1,2,5,2,4] 前缀最大值为 [3,3,3,5,5,5]，后缀最大值为 [5,5,5,5,4,4]

```python
def maxWater(self, arr: List[int]) -> int:
    length = len(arr)
    preMax, sufMax = [0] * length, [0] * length
    preMax[0], sufMax[-1] = arr[0], arr[-1]

    for i in range(1, length):
        preMax[i] = max(preMax[i - 1], arr[i])  # i-1保存了前缀最大值
    for i in range(length - 2, -1, -1):   # 注意循环条件
        sufMax[i] = max(sufMax[i + 1], arr[i])  # i+1保存了后缀最大值

    ans = 0
    for i in range(length):
        ans += min(preMax[i], sufMax[i]) - arr[i]
    # python 版本
    # for pre, suf, height in zip(preMax, sufMax, arr):
    #     ans += min(pre, suf) - height
    return ans
```



### 法二： 相向双指针（最优解）

时间复杂度： O(n)
空间复杂度： O(1)

就是将前缀和后缀最大值从数组改成了仅记录一个最大值

```python
def maxWater(self, arr: List[int]) -> int:
    left, right = 0, len(arr) - 1
    preMax, sufMax = 0, 0
    ans = 0
    while left <= right:
        preMax = max(preMax, arr[left])
        sufMax = max(sufMax, arr[right])
        if preMax < sufMax:
            ans += preMax - arr[left]
            left += 1
        else:
            ans += sufMax - arr[right]
            right -= 1

    return ans
```
